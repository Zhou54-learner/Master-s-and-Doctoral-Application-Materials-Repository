# 个人资料与写作中心

这是全仓库跨路线共用的**个人资料表达与写作方法中心**。

它不替代 `公共资料/事实核验`，也不接管任何路线/PI 的实时申请状态。它负责三件事：

1. 告诉所有工作区，个人事实应从哪里取、哪些表述可以安全复用；
2. 沉淀经过用户认可的写作原则、叙事资产和母版；
3. 为各路线/PI 工作区提供“怎么写”的共同底层规则，同时把“写给谁、对方现在做什么、该不该发”留在对应工作区。

## 一句话架构

> **main / 本中心：我是谁、事实边界、怎么写、可复用母版。**  
> **路线 / PI 工作区：项目事实、PI 证据、具体定制、发送状态。**

## 权威边界

- **事实权威源**仍是 `公共资料/事实核验/` 及其指向的原始证明；本中心不建立第二套互相竞争的事实数据库。
- 本中心中的“可写表述”只是基于当前已核事实的写作接口；若事实核验更新，以事实核验为准。
- PI / programme / deadline / funding / language requirement 等动态事实必须在对应路线工作区当轮重新核验，不放入个人母版。
- `READY_REVIEW` 不等于发送批准。所有外发仍遵守对应路线的用户手动确认规则。
