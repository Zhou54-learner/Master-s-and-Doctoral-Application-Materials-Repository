### 本科毕业论文 / 电磁仿真
安全核心：

> Used and extended an existing Python–CST parametric electromagnetic simulation and GA-based optimization workflow in the research group.

可以据事实进一步写：
- 扩展几何、图案、片阻等设计变量；
- 增加连通性/几何约束筛选；
- 自动化 CST solver invocation、reflection-response processing、batch data processing / visualization；
- 比较 thin solid-film 与 Ohmic Sheet modelling approaches；
- 讨论 modelling choice 对预测 response / optimization outcome 的影响。

### 尘埃等离子体合作研究
可以写：
- MATLAB numerical-data processing / polarization analysis / trajectory visualization；
- 参与论文所用数据与图件准备。

不要把该经历扩写成独立建立 dusty-plasma theory / solver。

### 论文
可按已核书目信息列两篇合作论文，并明确实际 contribution。作者顺序和贡献不等于主导研究；不要用 coauthored publications 暗示 first-author ownership。

## 3. 选择性呈现原则

- 联系版 CV / 首封不主动突出均分和排名是信息排序，不是隐瞒；正式系统要求时完整填写并提供 transcript / ranking。
- 不为了“坦诚”在第一屏主动列出所有薄弱课程，也不为了“包装”隐藏正式系统明确要求的信息。
- CET-6 可作为当前英语事实，但不能写成 IELTS/TOEFL 等价物。
- 第二学士、荣誉、课程、合作论文是否出现取决于材料目的，不要求所有版本完全同构。

## 4. 动态事实不进入白名单

PI 是否招生、programme eligibility、deadline、funding、language requirement、当前职位、研究关键词等必须由对应路线/PI 工作区当轮核验；本中心不把动态网页事实固化成长期个人资料。
