# 本目录协作规则

处理任何跨路线个人材料、CV、套磁信、research statement、SOP、PS 或推荐人 briefing 时：

1. 先读本目录 `README.md`。
2. 事实先回到 `../事实核验/`；不要因为旧邮件或旧 CV 写过就把旧说法当事实。
3. 个人经历的 ownership、能力边界以 `能力边界与禁写项.md` 为硬约束。
4. 写作优先遵循 `写作原则与语气规范.md`，不要机械模仿某一封案例。
5. 对 PI / 项目进行定制时，再进入对应路线工作区读取最新 evidence / tracker / contact package。
6. 新 PI 的连接句必须通过“换名字测试”：如果换成同领域另一个 PI 仍几乎成立，定制不足。
7. 中文审查镜像永不作为外发 canonical；任何实质修改先改英文，再同步中文。
8. 本中心只沉淀可跨路线复用的改进；单个 PI 的事实、联系人、发送日期、回复状态不得搬入本中心。
9. 不因追求“高级感”而增加申请人没有做过的方法、工具、阅读或研究结论。
10. 所有实际发送、系统提交和 Gmail 草稿行为仍需用户针对具体对象明确授权。
