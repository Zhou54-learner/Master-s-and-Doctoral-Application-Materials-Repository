# 套磁信母版｜研究问题驱动

这不是填空模板。它提供两种常用叙事结构，写新 PI 时应从真实经历重新组织。

## 邮件的唯一任务

> 让 PI 在很短时间内明白：你是谁、为什么是他/她、为什么值得进一步看 CV 或回一封信。

不要在首封里完成 SOP、Research Proposal 和完整自我辩护。

---

## Archetype A｜相邻物理平台迁移

适用：已有 EM / wave / device experience，希望进入 photonics、metamaterials、related device platform。

### P1｜身份 + 真实观察
- 一句身份 / intake。
- 直接进入最相关项目。
- 用一个具体观察代替泛泛兴趣。

逻辑例：
> 最初在做结构优化；模型比较让我开始注意 modelling 本身如何影响 response / design outcome。

### P2｜用动作证明执行能力
只留最能说明 ownership 的 2–3 个动作：
- adapted / extended existing workflow;
- added variables / constraints;
- automated simulation / processing.

不要把 CV 全搬进邮件。

### P3｜PI-specific bridge + 探索式未来
说明为什么这个 PI 的平台让你想继续走，但不宣布“natural fit”。

可用思路：
> I was interested in ... because it would let me continue working on wave/device problems while moving into a new physical platform.

### P4｜低摩擦问题
> May I ask whether you think this background could be a reasonable starting point for a Fall 20XX PhD project in your group?

---

## Archetype B｜从工具使用走向方法理解

适用：scientific computing / numerical methods / computational physics。

### P1｜先写原来的实际任务
例如：使用 commercial solver + Python workflow 做 device design / optimization。

### P2｜出现一个让思路变化的具体事件
例如：不同 modelling representation 对同一问题给出不同 response / optimization result。

自然转折：
> I realized that I understood how to run and automate the workflow better than I understood why the numerical result behaved the way it did.

### P3｜连接 PI 的 deeper layer
只点最关键的一两个 anchor，例如 Helmholtz / Maxwell / antenna electromagnetics；不要把 PI 主页关键词全部列出。

### P4｜开放式训练目标 + CTA
说明希望进一步理解什么，不要假装已有 solver-development research。

---

## 不要机械复用的句子

案例中的任何漂亮句子都不是“标准答案”。新邮件至少要重新检查：
- 这个触发兴趣的事件真的发生过吗？
- 它和该 PI 的研究之间连接是否具体？
- 是否为了显得定制而硬凑论文/关键词？
- 邮件是否仍像申请人本人，而不是像经过十轮优化的营销文案？

## Subject

清楚、具体即可：
- `Fall 2027 PhD inquiry — <specific research anchor>`

不要标题党，也不要塞满多个方向。
