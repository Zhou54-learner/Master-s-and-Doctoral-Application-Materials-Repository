# 中文审查镜像规范

## 定义

- 英文文件 = 外发 canonical source。
- 中文文件 = `REVIEW MIRROR / NOT FOR SENDING`。

中文镜像帮助本人判断事实、语气、逻辑和研究叙事，不承担第二套独立创作功能。

## 强制规则

1. 英文先改，中文后同步。
2. 中文不得为了“更顺”而静默增加或删除实质信息。
3. 中文发现问题后，把修改意见作用回英文 canonical，再重新生成镜像。
4. 中文镜像不进入任何邮件附件或申请系统。
5. 文件头应记录对应英文源和版本状态。
6. 若英文更新而中文未同步，中文立即标为过期。

## 翻译风格

中文目的不是字面直译，而是**逐义忠实**：
- ownership 强弱保持一致；
- `hope / would like / could` 等探索性程度保持一致；
- 不把英文里的谨慎未来语气翻成中文的强承诺；
- 不把英文具体动作翻成空泛“能力较强”。

## 审阅顺序

建议：
1. 先读中文，不看英文，判断“这是不是本人真正想表达的意思”；
2. 再对照英文检查语义强弱；
3. 最后检查若 PI 追问关键句，本人是否能自然解释。
