2. **师兄代码的角色与结构构思 ownership**
   - 师兄明确表示其代码仅作为 GA / Python-CST 流程参考，并给用户看了一些相关论文；
   - 师兄建议可以考虑立体结构，不是限定用户照搬某个最终几何；
   - 用户确认：具体十字竖直电阻膜构思、后续建模、自由度选择、GA / 搜索流程更新主要由本人和 AI 沟通逐步推进；
   - 用户当时确实读过一些 3D 吸波结构论文，但本人认为对最终思路影响有限；
   - 结构直觉是：从常见多层电阻膜型吸波结构出发，把电阻膜“竖起来”，形成十字交叉周期结构；这样在理想设计阶段看起来周期铺展不会中断，同时还能提供合适的几何 / 材料自由度。
   - 需要继续保持边界：这支持“具体结构构思由本人提出并推进”，不支持学术首创或论文级 novelty 判断。

3. **最早期模型与最终设计意图的区别**
   - 用户回忆：最早手工建模甚至只有一个有厚度的片状体；这一版可能已找不到；
   - 当前能找到的早期版本是两个十字交叉薄片，材料还沿用师兄样例组分，尚未形成 PET + ITO 柔性电阻膜，也没有金属背板；
   - periodic structures / 周期边界从很早阶段就采用；
   - 但“最终研究设计意图”从一开始就是 ITO 柔性电阻膜 + 金属底板 + 周期结构，只是前期花较多时间学习 CST 和 Python 脚本，早期 toy / scaffold 模型不能被误读成最终物理设计。

4. **材料参数原本具有采购约束**
   - 用户回忆：前期可选电阻膜厚度和片阻并不是完全连续自由，而是受常用可购买电阻膜型号限制，只有若干固定“厚度—片阻”组合；
   - 后期最终代码中片阻变成连续参数，何时 / 为什么从“商品型号约束”放宽为“理想连续参数搜索”目前用户记忆不完整；
   - 现有 R1 已发现类似 `SMH188H-60`、`SMH125H-80` 的型号线索，请继续只读搜索材料表、型号列表、脚本注释或聊天 / 文档，尽量还原这一步变化。

5. **GA 是课题一开始就计划使用，但理解是在做的过程中形成的**
   - 用户回忆：立项时就是奔着“GA + 仿真”的路线去的，课题方向由老师给出；
   - 当时本人对 GA 为什么必要、怎样设计搜索仍缺乏清晰概念；
   - 随着图案、片阻、尺寸等自由度增加，用户实际体会到：没有自动搜索，仅靠手工调参几乎不可完成；
   - GA 参数和优化路径本身也大量依赖 AI 帮助查资料、提出建议；
   - 因此更准确的成长叙事是：**先沿着既定 GA+仿真路线进入项目，随后在实际搜索空间和工作量中真正理解自动优化为什么必要。** 不要改写成“用户一开始就独立选择了 GA”。

6. **图案演化有明确的人在环设计线索**
   - 用户回忆：在较粗网格、仍采用等效实体电阻层建模时，就发现“纺锤形镂空 + 穿过中间的完整电阻膜条带”是效果较好的一类；
   - 后续更换为无厚度 Ohmic Sheet、提高图案精度后，并不是完全随机从零搜索，而是基于这类已有较好图案继续向下探索；
   - 最终演化为：Y 方向大体维持“纺锤形镂空 / 骨架”特征，X 方向由完整条带逐渐转向多个连通块；
   - 用户回忆，在最终结果出来后还尝试过取 1/4 图案再镜像得到更规整的对称图案，但性能未优于最终不完全规整的结果，且接近结题，因此未采用；
   - 用户倾向认为最终图案是自己在多轮尝试和搜索中逐渐形成的，而不是一次随机 GA 结果。
