# 本轮重分析图计划

核心问题：同管多音调是否形成分立台阶，台阶间距与管长、截面和弯管标签的关系是什么。

所有新图均为2026-10-06从历史材料重分析生成；不代替历史原图，不倒写为当年完成的分析。定量后端Matplotlib，历史MATLAB源码只读，用独立实现复核其整段单边FFT。

1. 直管全组频率图：按原组号绘制全部录音主峰，点为单次记录，组均值与样本标准差明示；横轴是记录组号，不是流速。
2. 台阶间距—管长：先展示全部直接相邻均值差，不删大间距；另把可能的缺阶/倍距解释单列，不能先按理论重编号再假称验证理论。
3. 代表录音时频图：对长录音/scale文件做本轮短时FFT，时间与Hz坐标；只有稳定持续频率段才称片内台阶，不把全谱多峰当成连续跳阶。
4. 弯管比较：按原始R、管长和第三字段分组。字段未确认时使用“原文件第三字段（单位待确认）”，不画虚构的曲率或流速坐标。

字体Microsoft YaHei，白底；蓝/橙区分截面族，彩色长度曲线辅以标记；轴单位Hz、cm/s按实际量填写。SVG文字可编辑，PDF矢量，PNG为300dpi预览。时频色图允许以数据栅格显示，注明重分析。

输出在output，数据CSV/JSON与生成源在同目录树。每图复核数值、图注、缺测标记、坐标和真实来源，保留异常/被排除记录及原因。
