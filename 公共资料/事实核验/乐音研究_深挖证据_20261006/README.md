## 重现

使用现有 `E:/CodexData/profile/.codex/runtimes/academic-figure-py311/Scripts/python.exe`，Python 3.11、NumPy 2.4.6、SciPy 1.17.1、Matplotlib 3.11.1；FFmpeg/FFprobe 在 PATH。脚本以自身位置定位输出，以明确的历史根目录定位输入，无自动联网、无上传、无历史文件写入。

在本包目录执行下列顺序，每行用上述 Python 解释器运行：

```text
source/analyze_audio.py
source/supplementary_provenance.py
source/deepen_and_plot.py
source/forensic_checks.py
source/validate_artifacts.py
```

`analyze_audio.py` 重新解码全部 351 份唯一内容；若只重画可从 `deepen_and_plot.py` 开始。绘图脚本可接一个额外目录参数，把图导出到新目录。验收脚本自动在临时新目录重绘，并逐像素比较四份 PNG。

图形 QA 调用本机 academic-figure 技能中的检查器；PDF 用 Poppler 实际渲染，SVG 用技能可用后端渲染。SVG 文字保持文本、标记及线条为矢量；F03 的时频热图是原始音频算出的栅格数据，明确允许该一个栅格对象，坐标和线图仍为矢量。SVG 需要 Microsoft YaHei 字体；PDF 嵌入字体，适合跨设备查看。
