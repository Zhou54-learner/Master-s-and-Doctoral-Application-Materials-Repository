## 4. 真实性与策略修正

这些修正用于后续所有新材料；旧档案原样保留供追溯，不再单独代表当前判断。

| 问题 | 修正后的执行口径 |
|---|---|
| “开发遗传算法”“自主搭建完整科研流程”过强 | 使用并改进已有参考基础上的 GA 优化流程；说清个人改动、支持与局限。未核代码前用 adapted / worked on，不用 from scratch |
| 把 CST 与 FEM 直接画等号 | 只确认电磁仿真工具经验；CST 具体求解器、时域/频域、网格与边界设置待原工程核验，不能宣称熟练有限元 |
| “inverse design”容易暗示 AI 反演 | 可称 simulation-based parameter optimization 或 optimization-based design；不是学习式逆映射、不是已掌握生成模型 |
| 从 PI 的物理约束论文推演出本人也遇过非物理解 | 这是类比，不是经历证据。必须找到本人真实失败案例才能写“我曾发现/解决” |
| AI 辅助编码变成独立软件研发能力 | 描述具体代码修改、测试、复查与工具支持；不隐藏对参考代码和 AI 的依赖，也不抹掉真实贡献 |
| 朱一舟被默认归物理路线 | 主聘工学院、学科材料科学与工程，物理系兼聘；真实报考学科须确认，先准备可迁移英文陈述 |
| 田静逸“实验为主体就降 B”、鲍芳琳“非重实验才合适” | 已被用户新偏好覆盖。改问科学问题、可诊断性、设备排队、平台支持、反馈频率和合理分工 |
| 刘仕 Wiki = 指导确定性高 | Wiki 证明公开知识资产存在；是否实际带教、响应速度、算力可用性仍待学生核验 |
