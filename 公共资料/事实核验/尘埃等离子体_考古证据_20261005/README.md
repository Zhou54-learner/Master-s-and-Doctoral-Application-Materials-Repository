本轮工具：`audit_sources.py`建立清单并只读解出源码／MLX图像；`inspect_data.py`只读解析FIG、XLSX和PDF；`verify_chain.py`检查数值／图像身份关系并提取少量代表CSV。它们只服务本次核验，不是原科研工作流，不执行MATLAB代码。全部输入位于源目录，派生输出写在本目录及`E:/CodexData/tmp/dusty_audit_20261005`。依赖为现有PyMuPDF，以及本轮独立临时目录中的NumPy/SciPy/olefile；没有更改科研代码环境。
