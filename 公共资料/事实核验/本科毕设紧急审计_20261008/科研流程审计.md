本轮新增发现：

1. **PET历史命令写入εr=3.1、tanδ=0.01，但两工程保存的介质损耗结果均为0。** `.TanD`值不能自动证明损耗模型已正确启用；该命令未显式设置TanDGiven/损耗模型开关。损耗是否启用、CST默认行为和参数来源仍待核。PPT只能写“脚本输入值”，不能写“已验证的PET耗散”。
2. **拓扑变异中的桥接/开槽分支不可达。** 最后生效调度函数的累计阈值为0.35、0.70、1.15，随机数在[0,1)，实际概率为点翻转35%、块变异35%、边缘生长/收缩30%；`else: bridge_or_slot_mutation`不能进入。仅存在函数不等于运行使用。（C:4958–4980）
3. **适应度存在浮点阈值问题。** 获选低端频率保存为4.800000000000001 GHz，未触发`f_low <= 4.80`的+7分奖励。按原始浮点数可复算score=89.63868001716894；若先将4.80当精确值会错算96.63868。原件不修，后续验证副本应明确频率容差/离散索引规则。（C:4711–4803；本轮数值复核）
4. **不能再说全功率“完全没有取得”。** 本轮恢复GA两种激励各10个功率样点、后期各11个样点。S矩阵功率和与导出总反射功率一致至约2.3×10⁻¹⁶；能量残差最大约5.48×10⁻⁵。它支持已保存模型内的功率核对，不能替代更严格网格、端口距离/模式数或材料验证。

## 1. 研究目标 → 结构设计

目标是2–18 GHz内使指定入射偏振的低反射连续频段尽可能宽；当年的优化器用同模反射阈值作代理指标。不是优化平均吸收率、双偏振最坏值或全角度吸收。（T摘要/第3–4章；C:4711–4803）

两块竖直PET正交：pet_x沿x展开、厚度沿y；pet_y沿y展开、厚度沿x。最终p=13.1409 mm，h=10.0731 mm；两PET厚0.188 mm。12×12的0/1矩阵表示电阻层去除/保留，不是PET挖空，也不是求解网格。电阻层为单侧二维Ohmic Sheet。底部用Zmin electric边界表示理想PEC，没有恢复实体铜板厚度或有限导电率。（H History块3、4、352；C:584–614、1529–1563、738–765；D）

来源分工：师兄建议立体方向并给GA参考；本人据回忆提出具体竖直十字构思，随后与AI推进建模和搜索。这个事实不等于学术首创。先固定少量材料/尺寸，随后条带/工字、6×6、9×9、12×12及片阻扩展有代码资产支撑；每一步的具体决策时刻和全部理由没有完整同期记录。（U）

## 3. 边界、激励和仿真过程

X/Y unit cell模拟无限周期；theta=phi=0为正入射。模板曾写Zmin expanded open，但后续set_ground_boundary覆盖为electric，应按最终History读配置，不能只看模板前半段。Zmax开放Floquet端口，入射沿−z，反射沿+z。（C:269–326、738–819；H块0/352/353；F）

本工程实际端口场：mode 1=TE(0,0)，E沿y；mode 2=TM(0,0)，E沿x。正入射时TE/TM命名依赖软件基底，不能把这个映射推广到所有工程。两mode分别求响应，parallel block excitation不等于相干混合入射。（F原始In_e1/e2场表）

有效调用链：`evaluate_individual`→缓存/硬筛选→`run_cst`设置双片阻→`decode`→`run_cst_for_params`→新工程/模板/PET/图案→最终边界/快速求解设置→`run_solver`→保存临时CST→`extract_metrics`读取复数S→返回指标/参数/路径→日志与最好个体导出。p/h由Python数值展开写入History；原工程参数表只含theta/phi，不是把所有设计量都写进CST参数表。（C:1747–1814、4669–4693、5134–5172）

求解器为频域、二阶四面体。GA快速配置关闭网格自适应；后期工程打开自适应并加入8.8/12/15.5 GHz的E/H/Powerloss监视器。后期日志显示18 GHz三轮自适应，网格5462→6621→7408，S差0.0019609、0.000580563；同时有网格警告。它是软件内部停止证据，不是13.20 GHz独立稳定性证明。（H块353–357及Result/Model.log；F）

## 4. S参数 → 功率 → 指标

这里用rᵢⱼ表示`SZmax(i),Zmax(j)`：j为入射mode，i为反射mode；全部在同一个Zmax端口。**r₂₁在这里是交叉偏振反射，不是穿过背板的透射。** 常见“两物理端口S21=透射”的记法不能机械套用。

对单位入射功率、正交且功率归一化的传播模式，Rⱼ=Σᵢ|rᵢⱼ|²。一般A=1−R−T，须包括所有开放反射与透射通道。理想PEC背板令T=0；本工程正入射背景为空气、周期13.1409 mm，首个非零衍射阶公式cutoff=c/p=22.8137 GHz，2–18 GHz远场传播通道只有两个零级偏振。高阶倏逝模仍可能影响近场和数值收敛，不能因不传播而宣称端口模式截断已收敛。（F；N）

通道求和及功率归一化的通用定义参照[COMSOL官方S参数说明](https://doc.comsol.com/6.3/doc/com.comsol.help.woptics/woptics_ug_modeling.5.30.html)；它只支持通用物理定义，不替代CST本工程端口核验。CST模式设置的直接来源是F索引内本机2025官方帮助。

RL=20log10|r₁₁|=10log10|r₁₁|²。−10 dB意味着该通道功率为入射的10%；必须加上其他通道才谈总吸收。GA fitness只读取r₁₁。N已恢复两工程的r₂₁很小，但r₂₂接近0 dB，故结构并不偏振不敏感。
