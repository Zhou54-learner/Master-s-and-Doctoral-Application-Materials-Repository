# 乐音研究考古取证资料

2026-10-05｜INTERNAL。结论与个人贡献分层只维护在[主报告](../乐音研究_历史内容与独立贡献考古_20261005.md)。

- `原件索引.json`：traindata 与 COMSOL/test 共 1,357 个原件的路径、字节数、SHA-256、北京时间修改时间；不是实验次数。
- `追加原件索引.json`：MATLAB 工作目录、编辑/命令历史、申报草稿及参考论文。
- `历史源码_*.m`：按原字节复制；仅取证，不作为当前运行入口。尤其旧 FFT 代码会写 `main_frequencies.xlsx`，不要在历史目录执行。
- `app1_*.xml.txt`：从 MLAPP 包静态提取的代码/元数据，非本轮重建 App。
- `表格单元格与元数据.json`、`FFT工作目录表格核读.json`、`比较图数据区域.json`：历史数据与图表范围；后者也记录某些表没有保留同版完整图表。
- `MATLAB历史命令_2024选段.json`、`MATLAB编辑器路径选段.json`：仅保留相关时期/路径。命令记录不能证明历史代码的每个版本相同或所有输出成功。
- `COMSOL静态模型摘要.json`：模型接口、几何、参数、研究、结果节点及解数据对象索引。不包含完整模型或许可证信息，不代表完成求解验证。
- `FIG对象核读.json`：两份历史时变音高图的对象/数值，不是 FFT 图，也没有新增分析算法。
- `音频FFT核对_本轮复算非历史结果.json`：2026-10-05 用原音频独立计算所得，仅核对历史链；没有运行历史 MATLAB 源码。
- `压缩与工程容器索引.json`、`字节去重摘要.json`、`定向正文检索.json`：搜索覆盖、压缩包/工程成员和去重证据；不复制无关私密正文。
- [核验汇总.json](核验汇总.json)：接替原聊天后完成的原件保全、15段数值匹配和相对链接验收。1,366 个原件的大小、SHA-256、修改时间均与考古索引一致；4 份历史代码副本和 3 张既有归档图均与源件字节相同；15 段重算均复现上一聊天核对结果，历史表格最大频率差为 4.6565×10⁻⁷ Hz（只反映表格小数保留，不是实验精度）。

`audit_history.py` 和 `inspect_chain.py` 是**本轮取证实现记录**，不是本科代码。前者用标准库读取原件；后者需要 NumPy/SciPy、FFmpeg/FFprobe，仅在新输出目录写核对材料。此次依赖位于本机临时目录，脚本保留实际运行路径供追溯，不自动安装或执行。脚本/JSON中的本地时间与元数据均不当成比赛认证时间。

图像复用[此前已归档M01–M03](../个人探索_20261004/素材)，原始模型、音频、视频、申报表和压缩包继续保留本地。最终PPT未找回；不据当前报告伪造一份历史最终稿。

`validate_takeover.py` 为本次接手续验的实现记录，只读源件，独立解码核对 15 段录音并直接读取历史表格，仅写本目录的核验汇总。它同样不执行历史 MATLAB 源码，不启动 COMSOL。审查另将口述备选中的“主要能量集中”修正为“最大谱峰”，避免把幅度谱峰值当作已统计的能量占比；现有 ownership 和未验证机理边界保持。
