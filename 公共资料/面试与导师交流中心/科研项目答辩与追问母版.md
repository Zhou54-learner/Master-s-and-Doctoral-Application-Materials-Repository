# 科研项目答辩与追问母版

状态：INTERNAL

本文件服务于所有导师交流中的 Research Defense。目标不是背答案，而是确保每段经历都能用一致、诚实、可追问的结构讲清楚。

## 每个项目统一六问

1. **问题：** 这个项目真正要解决什么科学 / 工程问题？
2. **方法：** 为什么选这些模型、算法、仿真或数据处理方法？
3. **本人贡献：** 我亲自完成了哪些步骤？哪些来自导师、师兄或合作成员？
4. **结果：** 得到了什么可验证结果？
5. **边界：** 哪些结论不能从现有结果推出？有哪些未完成验证？
6. **下一步：** 如果再做一个月 / 半年，我会先补什么？

## 本科毕设：默认最深追问

### 必须能讲清
- 电阻膜吸波结构的基本物理问题；
- CST 模型如何参数化；
- Python 如何驱动建模 / 求解 / 结果读取；
- 遗传算法在工作流里的位置；
- 原有结构、参考代码与本人增量的边界；
- 新增的几何、图案、双向片阻等设计自由度；
- 连通性等几何约束为什么需要；
- 分阶段搜索为什么这样安排；
- 薄实体膜与 Ohmic Sheet 的差异及比较动机；
- 保存结果中的同模反射口径与完整吸收验证的区别；
- 当前未完成的全端口功率平衡、网格 / 频率收敛等可靠性检查。

### 高频 ownership 追问
- 这个课题是谁提出的？
- 结构是谁设计的？
- 代码是谁写的？
- 你到底改了哪几处？
- 如果没有师兄代码，你能否重建工作流？
- 哪个 bug / 失败案例最能证明你真的做过？

回答原则：不防御，不争抢贡献；准确拆分输入、本人增量和最终闭环。

## 国家级大创 / 吸波材料合作

现阶段只使用已核贡献：
- 数据处理与可视化；
- 部分论文图件；
- 稿件文字工作；
- 项目成员身份。

待未来材料支持后，才可增加性能比较、物理量分析、实验参与等内容。

必须能回答：
- 项目研究的材料和目标是什么；
- 论文主要结论是什么；
- 自己处理的是什么数据 / 图；
- 自己没有做哪些实验或关键环节；
- 从这段经历学到了什么。

## 二维尘埃等离子体晶格波

已核贡献：
- MATLAB 处理模拟数据；
- 分析粒子运动的偏振特征；
- 粒子运动轨迹可视化；
- 输出合作论文部分数据 / 图件。

不要认领完整模型、求解器、理论推导或论文主导。

必须能回答：
- 晶格波问题的基本物理图像；
- 偏振特征在数据里如何体现；
- 自己的 MATLAB 输入、处理和输出分别是什么；
- 轨迹图如何从数据生成；
- 这段经历为什么和后续计算研究能力有关。

## 第三篇低参与论文 / 新会议稿

原则：署名不等于贡献。

- 第三篇 Nb2CTx 论文若被问到，先讲论文问题与主要结果，再明确本人参与有限；不把后来的学习倒推成历史贡献。
- 新会议稿在状态与个人贡献未核清前，不作为本人核心项目使用。若未来核实有 CST / Python / GA / 数据链条贡献，再进入正式答辩母版。

## 可靠性类追问

任何计算项目都可能被问：
- 结果怎么验证？
- 参数选择为什么可信？
- 模型是否收敛？
- 有没有 baseline？
- 仿真和实验是否一致？
- 是否存在过拟合 / 搜索偶然性？
- 你如何判断一个结果“物理上合理”？

不能回答时，区分：
1. 当时做过但记不清；
2. 当时没有做；
3. 现在知道这是应该补的验证。

“当时没做”比编造验证更安全，也更能显示科研边界意识。

## 表达标准

好的回答通常包含：

> 当时输入是什么 → 我做了什么 → 为什么这么做 → 得到什么 → 哪里仍然不确定。

避免：
- 只报软件名；
- 只报论文结论；
- 用“我们”掩盖本人贡献；
- 把会使用工具说成掌握完整理论；
- 被追问后才承认关键部分不是自己做的。
