# 导师定制覆盖层

状态：INTERNAL

共用面试母版解决“我是谁、做过什么”；导师定制层解决“为什么这些经历值得迁移到你的研究问题”。

## 默认只改四类内容

### 1. Research Hook
从 PI 当前公开研究中选 1 个真正能和本人经历连接的问题，不堆所有方向。

检查：
- 是否来自当轮核验的 PI / 实验室官方信息；
- 是否能用本人已有经历解释连接；
- 是否避免把相邻经验说成已经掌握目标技术。

### 2. Future Direction
未来方向保持“问题类型 + 方法兴趣 + 待学习技术”的开放结构。

推荐：
> 我希望进一步探索……；现有训练给了我……入口；目标体系中的……仍需系统学习；具体课题希望结合组内实际问题与导师讨论确定。

避免：
> 我博士期间一定要做某个具体课题 / 某个固定算法。

### 3. PPT 强调顺序
根据 PI 改变项目权重，而不是改历史事实。

示例：
- 光子学 PI：强调电磁结构、结构—响应、参数化仿真、模型比较；
- 计算材料 PI：强调自动化工作流、参数空间、数值可靠性与学习第一性原理的动机；
- 实验材料 PI：强调材料合作、数据解释、愿意进入实验闭环，但不冒充已有制备能力；
- 复杂系统 / 数值物理 PI：强调尘埃等离子体、数据处理、物理图像与数值分析。

### 4. 反问 PI
准备 2–4 个问题，优先：
- 如果进入组内，最可能从哪类问题切入？
- 对本科背景转入该方向，前 3–6 个月最重要的训练是什么？
- 某个课题中计算 / 实验 / 理论分别扮演什么角色？
- 学生通常如何获得日常指导与项目反馈？

首轮交流不必一次把名额、经费、毕业、带教、设备、工作时长全部问完。

## 70/30 原则

建议每次导师交流材料：
- 70%–80% 共用：教育、科研轨迹、毕设、真实合作经历、能力边界；
- 20%–30% 定制：研究连接、未来方向、强调顺序、反问。

如果为了换 PI 需要重写一半以上历史科研内容，通常说明材料设计出了问题。

## 换名字测试

完成定制后问：
> 如果把 PI 姓名换成同领域另一位导师，这两页仍几乎完全成立吗？

若答案是“是”，说明 Research Hook 仍过泛；应增加一个真实、可解释的 PI-specific 问题，而不是增加奉承语句。

## 事实边界

定制层不得改变：
- 21/46 排名与 80.20 自算均分口径；
- 论文作者与真实贡献；
- 毕设来自已有结构 / 仿真流程与参考基础；
- 尚未掌握的 DFT / MD / PyTorch / GNN / 微纳加工 / 光谱测试等技能；
- 未完成的仿真可靠性验证。

如果 PI 新回复提供课题、名额、学科、方法分工等信息，保存到该路线 / PI 工作区，不写回个人事实母版。
