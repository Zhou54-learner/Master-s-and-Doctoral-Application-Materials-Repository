# 通用理论背景补强

状态：INTERNAL

目标：围绕**申请人自己的科研工作**补足面试所需的物理与方法基础。PI 特有理论放在对应导师文件夹，本文件不承担拓扑光子学、纳米光子学等组内专属课程。

## 学习原则

每个概念按三档记录：

- **A｜会解释**：能不用术语堆砌地讲清物理图像；
- **B｜会读结果**：能看懂项目中的公式、图、数据或仿真输出为什么这样；
- **C｜会使用**：能在自己的模型 / 代码 / 数据处理中实际应用。

面试前，直接支撑本人项目的概念尽量达到 B–C；与 PI 方向相邻但尚未做过的概念达到 A–B 即可。

上述 A/B/C 是目标深度，不是现有能力评级。当前各主题均待本人学习/复述核对；按 `概念｜关联本人步骤｜来源｜目标深度｜当前证据/未核｜下一步` 记录，新增理解标为“面试学习后的新理解”。PI 概念使用同一深度定义，但详细笔记留在 PI 区。

## 一、电磁与吸波结构公共基础

需要逐步核清：

- 频域 Maxwell 方程；
- 边界条件与端口 / 周期性边界的物理意义；
- 复介电常数、复磁导率、损耗；
- 反射、透射、吸收与功率守恒；
- 阻抗匹配；
- 谐振、模态、品质因子；
- 片阻 / 表面阻抗；
- 薄实体膜与表面模型的近似边界；
- 周期结构与单元模型；
- 网格、频率采样、收敛与数值误差。

目标不是补成完整电动力学课程，而是能解释自己的模型为什么这样建、结果为什么这样读。

## 二、参数搜索与优化公共基础

需要逐步核清：

- 参数空间与设计变量；
- objective / fitness function；
- hard constraint 与 soft constraint；
- baseline 与 brute-force / random search；
- GA 的 selection / crossover / mutation；
- 搜索效率与局部 / 全局最优；
- stochastic optimization 的偶然性与重复性；
- 仅在解释本人搜索流程确有需要时比较 optimization-based design 与 inverse design；surrogate / 学习式方法主要留给相应 PI 的可选学习，不作为本人已有训练；
- 为什么“会调用 GA”不等于“开发了 GA”。

## 三、数据处理与科学计算公共基础

- 原始数据、派生量与最终图件的区别；
- 数据清洗、归一化、插值与采样的影响；
- 可视化如何服务物理判断；
- baseline / control / uncertainty；
- 结果可复现性；
- Python / MATLAB 脚本在科研链中的位置。

## 四、二维尘埃等离子体项目基础

需要根据原始论文与代码另行恢复，至少能解释：

- 二维晶格波的基本物理图像；
- 粒子位移 / 轨迹与偏振信息之间的关系；
- 本人处理的数据输入与输出；
- MATLAB 可视化如何支持论文中的物理判断。

未核实前不补造完整理论模型或求解器细节。

## 五、理论补强最终要回答的问题

每个项目都应能回答：

1. 为什么这个模型合理？
2. 为什么选这个数值 / 数据方法？
3. 哪个参数最重要，为什么？
4. 结果如何验证？
5. 哪些误差会让结论失效？
6. 如果结果异常，第一步排查什么？

这些问题比背更多术语更重要。
