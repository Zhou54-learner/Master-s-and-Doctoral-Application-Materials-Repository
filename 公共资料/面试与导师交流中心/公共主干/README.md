# 面试准备公共主干

更新：2026-09-30｜INTERNAL

本目录是所有已获得 PI 实质性交流意愿后的**公共准备主干**。目标不是为某位导师写一套材料，而是把申请人自己的科研事实、工作流、理论背景与表达材料整理成可反复复用的研究资产。

## 核心原则

> **先还原自己，再理解对方，最后定制表达。**

公共主干只回答四类问题：

1. **我过去到底做了什么？**——逐项目还原问题、方法、本人步骤、输入输出、结果、局限与 ownership。
2. **我现在真正会什么？**——区分 `Already demonstrated / Transferable / Need to learn`。
3. **哪些关键步骤值得重新复现？**——必要时通过只读检查、最小 demo、toy workflow 或重新绘图恢复记忆，但当前复现不得倒写成本科历史贡献。
4. **为了把自己的工作讲明白，还缺哪些理论背景？**——围绕本人项目补物理、数值、算法、可靠性与验证概念，而不是为了某位 PI 临时堆术语。

PI 本人、课题组方向、重点论文、组内概念框架和最终定制全部留在各路线的 `面试与导师交流/<PI>/` 工作区。

## 项目优先级

当前默认：

1. **本科毕设：电阻膜微波吸收结构**——最深 Research Defense；必要时恢复 Python-CST / GA / 结果处理最小工作流。
2. **二维尘埃等离子体晶格波**——恢复 MATLAB 数据处理、偏振分析、轨迹可视化的真实输入—处理—输出。
3. **国家级大创 / 吸波材料合作**——先做证据审计；仅在原始材料支持后增强贡献描述。
4. **低参与论文与新增会议稿**——先核真实历史贡献，不能因重新学习论文而制造过去 ownership。

## 与 PI 工作区的关系

每位 PI 获得实质交流意愿后，新建独立文件夹。该文件夹只做：

- PI / 课题组研究地图；
- 最有价值的文献与研究主线；
- 与组内工作相关的概念框架；
- 申请人的能力迁移接口；
- 基于公共 PPT / Research Defense 母版的 20%–30% 定制；
- 会议安排、特有追问、反问和会后复盘。

不得为了匹配某个 PI 改写历史贡献、成绩、作者顺序或技能边界。
