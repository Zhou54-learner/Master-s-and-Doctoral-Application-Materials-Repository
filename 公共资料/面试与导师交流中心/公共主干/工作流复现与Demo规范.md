# 工作流复现与 Demo 规范

状态：INTERNAL

用途：当旧项目细节记忆模糊时，通过安全、最小、可解释的复现恢复真实工作过程。复现的目标是**找回操作链和科研判断**，不是给历史经历补造新贡献。

## 一、复现分三级

### R1｜只读恢复
优先做：
- 找到原始代码、模型、数据、图源、日志、报告；
- 查看文件时间、目录结构、变量名、注释和历史输出；
- 对照论文 / 毕设中的图和表找到生成来源；
- 不修改源目录，不运行可能覆盖结果的脚本。

### R2｜最小可运行 Demo
只重建关键链条，例如：
- 参数字典 → CST / 仿真输入；
- toy 参数扫描 → 结果解析；
- 小规模 GA → fitness → selection / crossover / mutation；
- MATLAB 原始数组 → 偏振指标 / 轨迹图。

Demo 应放在独立新目录并标注：`2026面试复习重建`。

### R3｜补充验证
如果面试前有价值，可重新做：
- 一小组 baseline；
- 结果读取与绘图；
- 网格 / 频率采样敏感性；
- 简单模型对比；
- 物理量计算核对。

这些属于**当前新增复核**，不能倒写成“本科期间已经完成”。

## 二、每个 Demo 必须记录

1. **复现目的**：想恢复哪段记忆或验证哪个理解？
2. **原始来源**：对应哪个旧代码 / 数据 / 模型？
3. **当前改动**：为使其可运行做了哪些修改？
4. **输入 / 输出**：最小输入是什么，产生什么输出？
5. **与历史工作的关系**：历史上做过、部分做过，还是现在新增？
6. **面试可讲结论**：它帮助本人重新确认了什么？

## 三、本科毕设复现优先级

建议按以下顺序：

1. CST 模型参数及结构变量；
2. Python 与 CST 的调用接口；
3. 单个候选结构从参数到仿真结果的完整链；
4. GA 编码、fitness、筛选与约束逻辑；
5. 批量结果读取、带宽 / 反射响应计算与可视化；
6. 薄实体膜与 Ohmic Sheet 的模型差异；
7. 结果可靠性：同模反射与完整功率平衡、收敛等尚未完成项。

## 四、禁止事项

- 不在原始源目录直接运行会覆盖历史结果的优化器；
- 不为了“看起来更强”重写旧代码后声称是本科原版；
- 不把 AI 当前帮助重建的代码说成历史上独立完成；
- 不因成功复现一个 toy demo 就扩大到“熟练软件工程 / FEM / ML”等能力；
- 不删除失败记录。真实 bug、调试和边界往往是最好的 ownership 证据。
