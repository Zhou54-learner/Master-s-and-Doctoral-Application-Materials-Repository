# 面试资料母版与输出规范

状态：INTERNAL

本文件负责把公共主干的研究资产转成可供不同 PI 复用的面试材料。最终 PI-specific PPT 不在这里生成，而在对应导师工作区完成。

## 一、公共母版组成

### 1. 个人开场
- 30 秒自我介绍；
- 2 分钟扩展版；
- 教育背景只保留与科研训练相关的信息。

### 2. 科研轨迹
不是按论文数量罗列，而是体现：

> 早期合作中的数据 / 仿真 / 图件工作  
> → 本科毕设中更完整的参数化建模、自动仿真、搜索与结果分析  
> → 逐步形成对计算 / 物理建模 / 结构—响应问题的兴趣。

### 3. 核心项目页
默认本科毕设占最大篇幅。每页至少回答：
- 问题；
- 方法；
- 本人贡献；
- 关键结果；
- 一项局限 / 下一步。

### 4. 其他科研
合作项目只写真实 contribution，不为了凑页数扩大 ownership。

### 5. 技能与能力迁移
使用 `Already demonstrated / Transferable / Need to learn`，避免软件清单式自夸。

### 6. 未来方向
公共母版只表达稳定兴趣：物理建模、计算设计、结构—响应、数据 / 自动化等。具体科学问题留给 PI 覆盖层。

## 二、默认 PPT 结构

首次 PI 交流默认：**5–8 分钟、6–8 页**。若 PI 只说“介绍工作”，可更偏科研；若 PI 明确要求教育经历 / 未来方向，则按要求增加对应页。

建议页序：

1. About Me / Education；
2. Research Trajectory；
3–4. Thesis / Core Project；
5. Other Research；
6. Skills / Research Approach；
7. Future Interests / Why this group；
8. Questions / Thank you。

不是固定模板；PI 要求优先于母版。

## 三、PI 覆盖层只能修改什么

通常只改：
- 项目强调顺序；
- 一页研究连接；
- 未来方向落点；
- 该 PI 特有概念与论文 hook；
- 特有追问和反问。

不能修改：
- 历史事实；
- 本人 contribution；
- 作者顺序；
- 成绩口径；
- 已掌握 / 未掌握技能边界。

## 四、输出前 Gate

任何项目进入最终 PPT 前，应通过：

- ownership 表完成；
- 工作流能按时间顺序讲；
- 关键物理 / 方法问题至少达到 A–B 理解；
- 结果口径核实；
- 未完成验证能主动说明；
- 图件来源明确；
- 被追问“这一步是不是你做的”时不需要临场改口。

## 五、面试后的反向沉淀

如果某次 PI 交流暴露出通用短板，例如：
- 不会解释某个本项目基础概念；
- 某段 ownership 模糊；
- 某个图无法说明输入输出；
- 自我介绍过长；

应回写公共主干，而不是只修该 PI 的 PPT。这样下一场交流直接受益。
