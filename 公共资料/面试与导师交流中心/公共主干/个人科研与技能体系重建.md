# 个人科研与技能体系重建

状态：INTERNAL

目标：把 CV 上的一行经历还原成**可以连续追问、可以解释为什么、必要时可以重新演示关键步骤**的真实科研工作流。

## 每个项目统一记录

### A. 科研问题
- 项目想解决什么问题？
- 为什么这个问题值得做？
- 最终评价指标是什么？

### B. 起始输入
- 课题由谁提出？
- 初始结构 / 数据 / 代码 / 仿真环境由谁提供？
- 当时本人已经会什么、不会什么？

### C. 本人实际步骤
按时间顺序写，不按简历语言概括：
1. 收到什么输入；
2. 做了什么操作或判断；
3. 使用什么软件 / 代码；
4. 产生什么中间结果；
5. 遇到什么问题；
6. 怎么调试或修改；
7. 最后输出什么。

### D. Ownership 四栏表
| 导师/师兄/合作成员输入 | 本人实际完成 | 已有验证/证据 | 尚未验证/不属于本人 |
|---|---|---|---|
| 待填 | 待填 | 待填 | 待填 |

### E. 理论与方法
- 当时真正理解到什么程度？
- 哪些理论当时只是工具层面使用？
- 为面试需要补到什么深度？

### F. 结果与可靠性
- 结果是什么？
- 为什么认为结果有意义？
- 做过哪些 baseline / 收敛 / 对比 / 实验验证？
- 哪些验证当时没有做？

### G. 复盘
- 如果现在重新做一个月，第一件补什么？
- 如果导师追问一个 bug / 失败案例，最真实的例子是什么？
- 这段经历最终形成了什么可迁移能力？

## 当前项目顺序

### 1. 本科毕设｜电阻膜微波吸收结构
面试前要求达到最高熟练度。重点恢复：

`物理问题 → CST 模型 → 参数定义 → Python-CST 调用 → GA / 搜索 → 几何约束与筛选 → 结果读取 → 可视化 → 模型比较 → 可靠性边界`

已知真实性边界：课题来自导师；师兄提供过结构思路、参考代码与 CST 环境；本人在此基础上学习、修改、扩展、调试和推进工作流。不得说成从零发明结构、从零开发 GA 或独立搭建全部软件系统。

### 2. 二维尘埃等离子体晶格波
重点恢复：

`模拟数据输入 → MATLAB 数据处理 → 偏振特征分析 → 粒子轨迹可视化 → 图件 / 合作论文输出`

不得认领完整模型、求解器、理论推导或论文主导。

### 3. 国家级大创 / 吸波材料合作
现阶段先做原始材料考古：原始数据、Excel / Origin / MATLAB / Python 文件、图源、修改记录、报告 / PPT、聊天 / 邮件讨论等。

只有证据支持后，才能从“数据处理、部分图件、稿件文字工作”升级到更具体的数据比较或物理分析贡献。

### 4. Nb2CTx 论文
当前低参与。目标只是能够诚实解释论文研究问题、方法和主要结果；重新学习不创造历史 contribution。

### 5. 新会议稿
先核提交状态和本人真实贡献，再决定是否进入正式面试主线。

## 技能矩阵

每次重建后同步维护：

| Already demonstrated | Transferable | Need to learn |
|---|---|---|
| CST 电磁仿真、Python 科学脚本/自动化、MATLAB 数据处理、GA 使用、数据可视化等已核能力 | 参数化建模、受约束搜索、结构—响应分析、自动化科研工作流等迁移能力 | 具体 PI 方向所需的新理论、仿真平台、实验技术或 ML / DFT 等未掌握技术 |

最终所有 PPT 和口述只能从这张矩阵向外写，不能反过来为了 PPT 补造能力。
