# 个人科研与技能体系重建

状态：INTERNAL

目标：把 CV 上的一行经历还原成**可以连续追问、可以解释为什么、必要时可以重新演示关键步骤**的真实科研工作流。

## 来源与记录方式

先读[公共项目入口](README.md)、[申请人事实审计](../../事实核验/材料审计与申请人事实.md)和[较新毕设核验](../../事实核验/毕设与新增个人证据核验_20260926.md)。以下是准备模板，不是新事实库；每项结论附事实源的章节或文件定位，未知保留待核。科研考古得到的功能、文件时间或注释不直接证明作者归属。

每条记录加 `性质｜发生日期或待核｜来源定位｜确认程度｜本人当前复述证据`，性质采用[四类时间标签](工作流复现与Demo规范.md)。不要把现在能解释等同当时独立完成。

## 每个项目统一记录

### A. 科研问题
- 项目想解决什么问题？

4. 产生什么中间结果；
5. 遇到什么问题；
6. 怎么调试或修改；
7. 最后输出什么。

### D. Ownership 四栏表
| 导师/师兄/合作成员输入 | 本人实际完成 | 已有验证/证据 | 尚未验证/不属于本人 |

| 待填 | 待填 | 待填 | 待填 |

### E. 理论与方法
- 当时真正理解到什么程度？
- 哪些理论当时只是工具层面使用？

### F. 结果与可靠性

- 这段经历最终形成了什么可迁移能力？

## 当前项目顺序

### 1. 本科毕设｜电阻膜微波吸收结构
面试前要求达到最高熟练度。重点恢复：

`物理问题 → CST 模型 → 参数定义 → Python-CST 调用 → GA / 搜索 → 几何约束与筛选 → 结果读取 → 可视化 → 模型比较 → 可靠性边界`

当前真实性边界（2026-09-30细化）：课题来自导师；师兄提供GA参考、论文及立体结构建议，并指导Ohmic建模方法和场监视器。本人确认具体竖直十字膜构思、应用建模、自由度和搜索更新由自己与AI协作推进。新找到的师兄原件不含最终PET片阻图案体系。不得说成结构学术首创、从零发明GA或独立逐行搭建全部软件系统。详见[事实续核](../../事实核验/本科毕设R1_20260930/核验记录.md)与[R1讲义](项目重建/本科毕设/README.md)。

#### 毕设逐项核对清单（追问入口，不是新增贡献结论）

| 需还原的环节 | 查什么、回答什么 | 不能越过的边界 |
|---|---|---|
| 导师 / 师兄输入 | 课题、初始结构、参考代码、CST 环境分别由谁提供；参考包是否可定位 | 已找到本人确认的GA参考TXT；不等于全部附件齐全，不逐行推定后续作者 |
| 本人增量 | 哪个文件/版本改了什么变量、筛选、搜索或结果处理；一个真实调试例子及本人确认 | 功能存在不证明本人独立实现；参考代码、在线资料和 AI 支持单列 |
| Python–CST | 参数输入 → 几何/材料/边界与激励 → 调用求解 → 结果树/文件读取 → fitness → 保存 | 实际接口和有效函数定义以代码为准；先静态走读，不直接运行原优化器 |
| GA / 搜索 | 编码、目标函数、选择/交叉/变异、阶段切换与停止；本人具体改了哪部分 | 使用/调整流程不等于从零开发 GA；无对照不宣称算法优势 |
| 几何约束 | 图案、尺寸、片阻自由度及连通性筛选在哪里实现，哪些是硬约束/惩罚 | 不将缺少消融的性能变化全归因于某一改动 |
| 薄实体膜 / Ohmic Sheet | 各自的参数、边界假设、比较条件与保存结果在哪里 | 模型比较不等于实验验证或已证明某模型绝对准确 |
| 结果处理 | 读取哪个 S 参数、单位、频率网格、阈值、带宽端点及图源 | 13.20 GHz 为同模反射采样带宽；82.5% 为频窗覆盖比例，不是总吸收率 |
| 验证 | 历史已有证据、全端口功率/网格/频率收敛缺口和本轮新验证分别列 | 已核频域求解/四面体网格仍不等于 FEM 熟练；新验证不回填历史 |

### 2. 二维尘埃等离子体晶格波
重点恢复：

`模拟数据输入 → MATLAB 数据处理 → 偏振特征分析 → 粒子轨迹可视化 → 图件 / 合作论文输出`

不得认领完整模型、求解器、理论推导或论文主导。

### 3. 国家级大创 / 吸波材料合作
现阶段先做原始材料考古：原始数据、Excel / Origin / MATLAB / Python 文件、图源、修改记录、报告 / PPT、聊天 / 邮件讨论等。

只有证据支持后，才能从“数据处理、部分图件、稿件文字工作”升级到更具体的数据比较或物理分析贡献。

### 4. Nb2CTx 论文
当前低参与。目标只是能够诚实解释论文研究问题、方法和主要结果；重新学习不创造历史 contribution。

### 5. 新会议稿
先核提交状态和本人真实贡献，再决定是否进入正式面试主线。

## 技能矩阵

每项技能同时填下面三个维度；这是唯一公共记录格式，不把可迁移推测当成已掌握目标领域。

| 技能项 | Already demonstrated：已演示范围、证据及时间性质 | Transferable：可迁移的方法与条件（判断） | Need to learn：待学内容与下一步 |
|---|---|---|---|
| CST建模与自动化 | 历史工作：本人确认手动→PET/电阻膜脚本化，与AI协作；History调试有原件及回忆支持（见事实续核U01/S02/S08） | 将重复建模转为参数化实验，需学习目标软件/物理模型 | 端口功率、网格误差、模型假设；R1讲义不等于已掌握FEM |
| GA使用与应用调整 | 历史工作：参考框架上推进混合变量、图案和筛选；具体函数手写范围UNKNOWN（U01/S02/S12） | 把研究目标转为变量、约束和评价；需检查目标适当性 | 权重敏感性、随机性、基线与搜索收敛，不认领GA方法原创 |
| 结果整理与场图 | 历史工作：保存曲线/日志，本人确认最初手动导场图；自动场导出未找到（U01/S03/S10） | 组织模型—参数—响应证据，需保持量纲/归一化 | 同模与总吸收、表面/体损耗积分及图源核对 |
| 模型比较与可靠性 | 历史工作：薄实体与sheet尝试，后期有软件自适应记录；严格对照与最终曲线对应尚未闭合（S04/S05/S06） | 比较近似与识别验证缺口；不等于已具完整验证能力 | 同参数对照、独立网格/频率敏感性、制造条件 |

初始范围从上述事实源提取 CST 使用、Python 脚本修改、GA 使用/调整、MATLAB 数据处理等已核经历；本轮没有新增熟练度判定。只有本人实际复述或操作支持后，才记录当前理解提升；不能从助手生成 Demo 推定独立软件工程能力。PI 特有技术在 PI 区列需求并引用本矩阵，公共历史能力不随 PI 改写。
