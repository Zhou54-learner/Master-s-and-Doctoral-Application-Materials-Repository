本人截图显示 Mermaid 8.14.0 词法错误。本轮在同版本中复现原图失败；将所有中文节点标签加引号，使用 `graph TD`，双向关系拆成两条普通有向连接。修正后的代码通过同版本解析及浏览器实际渲染，共 9 个节点、11 条有向连接；已查看导出图像。

PNG 与 SVG 均由该修正代码在 Mermaid 8.14.0 中直接导出，作为不支持 Mermaid 的预览器的备用显示。图中连接表示物理关系；不把场、材料响应与散射解释为依次单向发生的过程。
