# 通用PPT与口述母版

状态：INTERNAL｜用途：导师交流 / 预面试的共用底稿

## 推荐总量

默认 6–8 页，5–8 分钟主陈述。若对方明确要求更长，再扩展，不默认做成正式答辩式长 PPT。

## 1｜About Me / 教育背景

目的：30 秒内让 PI 知道申请人是谁。

建议包含：
- 哈尔滨工业大学应用物理学本科，2026 届；
- 专业排名 21/46；
- 研究兴趣用宽口径表达，不把方向锁死；
- 1 行技能入口：Python/CST、MATLAB、参数化仿真与数据分析。

不建议：把成绩单逐科列出、主动突出弱理论课、解释过多第二学位背景。

## 2｜Research Trajectory / 科研轨迹

目的：把多段经历从“散点”组织成成长轨迹。

建议主线：

> 早期合作科研中的数据 / 图件 / 数值处理  
> → 对结构—响应、数值分析与科研协作的真实接触  
> → 本科毕设中承担更完整的参数化建模、自动仿真、搜索与结果分析  
> → 希望在研究生阶段继续深化物理建模、计算设计与必要实验训练。

这页强调“经历如何逐步加深”，不强调论文数量。

## 3–4｜Core Project：本科毕业设计

这是默认篇幅最大、追问最深的部分。

### 第 3 页：问题与方法
- 研究问题是什么；
- 为什么手工调参 / 高维搜索存在困难；
- CST 模型、Python 自动化、遗传算法在流程中分别做什么；
- 本人从已有结构 / 仿真流程出发，具体扩展了哪些设计变量与筛选逻辑。

### 第 4 页：结果、比较与局限
- 展示 1–2 张最能说明问题的结构 / 曲线 / 流程图；
- 说明薄实体膜与 Ohmic Sheet 等模型比较；
- 解释结果能支持什么；
- 主动保留边界：同模反射结果不等于完整总吸收验证；全端口功率、网格 / 频率收敛等未完成项不冒充已完成。

口述重点：PI 应能听出“我不是从零发明算法，但我确实推进了一个较完整的计算研究链条”。

## 5｜Other Research Experience / 其他科研经历

默认放在一页，不和毕设抢篇幅。

可包括：
- 国家级大学生创新创业训练计划：吸波材料研究；
- 二维尘埃等离子体晶格波：MATLAB 数据处理、偏振特征、粒子轨迹可视化；
- 已核论文只作为成果证据，不用论文数量代替本人贡献。

如果后续找到大创或新会议稿的可核个人贡献，再更新事实源后进入本页。

## 6｜Transferable Skills / 我能迁移什么

这页不是技能清单，而是解释迁移逻辑。

可复用框架：

> 电磁结构建模 → 新体系中的结构—响应问题  
> 参数化仿真 → 系统探索设计空间  
> Python 自动化 / 搜索 → 可重复的计算工作流  
> MATLAB / 数据分析 → 结果解释与可视化  
> 合作科研 → 在新方向中继续补理论、方法和实验技能

不要把 CST 等同 FEM 熟练度，也不要写成已经掌握 DFT / MD / PyTorch / GNN 等未核技能。

## 7｜Future Directions / 未来希望探索的方向

这页必须开放，不写成假定博士课题。

推荐结构：
1. 我长期对什么类型的问题感兴趣；
2. 现有训练为什么提供入口；
3. 在目标组希望进一步学习什么；
4. 具体方向由真实课题和导师讨论后确定。

示例逻辑：

> 我逐渐对“如何利用物理建模和计算方法理解并设计结构—响应关系”产生稳定兴趣。现有训练主要在微波电磁结构、参数搜索和数据分析，希望在研究生阶段把这种思路迁移到新的物理体系，并进一步学习相应理论、数值方法及实验验证手段。

## 8｜Why This Group / Discussion

若交流较短，可与第 7 页合并。

只做 2–3 点定制：
- PI 当前真实研究问题；
- 申请人的哪个已有能力能形成入口；
- 申请人希望在该组补什么训练。

最后准备 2–4 个真正想问的问题，不在 PPT 上堆成长问卷。

## 三种口述长度

每个核心项目至少准备：
- **30 秒版**：一句问题 + 一句本人贡献 + 一句结果 / 收获；
- **2–3 分钟版**：问题—方法—贡献—结果—局限；
- **8–10 分钟版**：可进入模型、参数、代码流程、可靠性与失败案例。

面试时根据 PI 追问深度切换，不把所有细节塞进主陈述。
