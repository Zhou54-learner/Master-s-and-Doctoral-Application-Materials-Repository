# 面试与导师交流准备中心

更新：2026-09-30｜INTERNAL

这是跨路线共用的**面试 / 导师线上交流 / 预面试准备中心**。它处理的是“已经获得实质性交流意愿之后，如何把已有个人事实组织成可讲、可答、可按导师定制的材料”。它不新增申请路线，也不改变各路线的项目或联系状态。

## 一句话架构

> **公共主干：先把申请人自己的科研、工作流、理论背景和表达母版做扎实。**  
> **PI 工作区：再理解导师 / 组内研究，并完成 20%–30% 的定制覆盖。**

本中心不替代：
- `公共资料/事实核验/`：个人事实与原始证据的权威源；
- `公共资料/个人资料与写作中心/`：CV、Email、SOP/PS、Research Statement 的写作方法中心；
- 各路线联系记录：回复、会议邀请、时间、结果等真实事件的唯一状态入口。

这四层的边界必须保持单向引用：面试中心读取已核事实和已定稿的写作资产；PI 的课题、名额、会议时间、会议号及会后新事实留在对应路线 / PI 工作区和联系记录，不回写公共个人事实母版。

## 什么时候进入这个工作区

只有出现**实质性正向回复**后才启动，例如：
- PI 主动提出腾讯会议 / Zoom / Teams 交流；
- 明确要求准备 PPT、自我介绍、科研汇报或未来方向；
- 要求进一步面试、组会汇报或与组内成员交流。

普通“收到 / 欢迎申请 / 请走系统”不自动触发完整面试准备。

`REPLIED / MEETING REQUESTED` 表示已收到实质回复并被邀请交流；如已进入助理排期但时间未定，可追加 `SCHEDULING`。这些都不是 `SUBMITTED`、`OFFER` 或学校正式面试。会议日期、时间、时区和会议号未知时保持待确认，不自行补填。

## 两层工作区

### A. 公共主干

入口：[`公共主干/README.md`](公共主干/README.md)

负责跨 PI 复用的 70%–80%：
- 个人科研与技能体系重建；
- 旧项目工作流还原；
- 必要的最小 Demo / toy workflow；
- 本人项目相关理论背景补强；
- Research Defense；
- 通用 PPT / 口述 / 高频问答母版。

当前公共主干资产：
- [`个人科研与技能体系重建`](公共主干/个人科研与技能体系重建.md)
- [`工作流复现与 Demo 规范`](公共主干/工作流复现与Demo规范.md)
- [`通用理论背景补强`](公共主干/通用理论背景补强.md)
- [`面试资料母版与输出规范`](公共主干/面试资料母版与输出规范.md)

### B. PI 工作区

每位 PI 获得实质交流意愿后，在对应路线新建：`面试与导师交流/<PI>/`。

负责：
- PI 本人学术轨迹；
- 课题组研究地图与成员能力拼图；
- PI 高参与 / 高价值代表文献；
- 组内相关理论概念和研究逻辑；
- 与申请人已有能力的迁移接口；
- 基于公共母版的 PPT 定制、特有追问、反问和会后复盘。

当前 A 线实例：
- `A线_西湖博士/面试与导师交流/田静逸/`
- `A线_西湖博士/面试与导师交流/刘癸庚/`

## 现有通用母版

1. [通用PPT与口述母版](通用PPT与口述母版.md)：教育背景、科研轨迹、核心项目、其他经历和开放式未来方向的基础结构。

## 推荐工作流

### Phase 0｜记录邀请要求
在对应路线 / PI 工作区记录：
- 对方原话与来源；
- 会议形式；
- 日期 / 时间 / 时区；
- PPT 或语言要求；
- 对方明确要求讲什么。

不要把“交流”自动升级成学校正式面试，也不要自行补不存在的考核要求。

### Phase 1｜公共主干
先把本人经历恢复到真实可答状态：
- ownership；
- 工作流；
- 理论背景；
- 结果口径；
- 可靠性与未完成验证；
- 30 秒 / 3 分钟 / 10 分钟讲法。

必要时做当前复现 Demo，但必须与本科历史贡献分开记录。

### Phase 2｜PI 研究地图
再深入理解：
- PI 研究轨迹；
- 当前组方向；
- 重点文献；
- 组内方法与实验 / 计算闭环；
- 本人真正可能的学习接口。

### Phase 3｜PI 定制
通常只改：
- 研究连接页；
- 未来方向页；
- 1–2 个强调项目；
- 该 PI 特有追问与反问。

不要因为换导师而改变历史贡献、作者身份、成绩或技能边界。

### Phase 4｜模拟交流
至少做一轮：
- 连贯陈述；
- 毕设深追问；
- 其他项目贡献追问；
- PI 方向基础概念；
- 未来方向与“为什么这个组”；
- 成绩 / 排名 / 第二学位 / 英语等背景问题；
- 申请人向 PI 的反问。

### Phase 5｜会后复盘
会后在对应路线记录：
- PI 明确说了什么；
- 课题 / 名额 / 学科 / 培养方式的新增事实；
- PI 对申请人的评价或疑问；
- 后续动作与时间点。

把 PI 原话、用户确认与分析判断分开。

## 当前使用原则

- 面试内容高度复用，但**不是一份 PPT 发给所有导师**。
- 共用部分强调“我做过什么、怎么思考”；定制部分强调“这些能力为什么值得迁移到你的问题”。
- 不为了迎合 PI 把未来方向说死。
- 不假装精读未读论文；使用具体论文 hook 前，本人必须准备到可以解释。
- 中文交流时可使用英文图表、术语和页标题；若 PI 未要求英语，不把展示变成额外英语考试。
- PPT 是交流辅助，不是 CV 的逐页朗读。
