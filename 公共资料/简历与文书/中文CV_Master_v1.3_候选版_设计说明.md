# 中文 CV Master v1.3 候选版｜设计说明与审查意见

2026-09-28｜INTERNAL｜供本人、Chat 与 Work 审查；**不是 READY，不替代已冻结的 Master v1.2，不得直接外发。**

**Work已完成审查与实排：** 见[审查结论与一页Word/PDF](中文CV_Master_v1.3_审查结论与验收.md)。下文呈现策略为原提案；事实来源、改动和实测以审查记录为准。新版仍CANDIDATE，不合并或升级READY。

候选内容源：[`周子靖_中文学术简历_v0.6_INTERNAL.md`](周子靖_中文学术简历_v0.6_INTERNAL.md)

## 1. 本轮为什么要改

此前 Master v1.2 的策略是极度保守：一页、两个科研项目、两篇有明确贡献的代表论文，避免任何“为凑数量而增密”的风险。该策略在真实性上是安全的，但在当前申请阶段出现了另一个风险：**第一次套磁时，PI 可能在 20–30 秒扫读中把申请人理解为“科研经历偏少、只有一个毕设和两篇浅合作论文”**，从而在来不及进一步追问真实工作细节前就降低回复优先级。

用户本轮明确调整目标：不把弱经历包装成强经历，也不把挂名论文说成主要成果；但应尽量完整呈现真实存在的科研参与、正式论文协作和项目经历，让 CV 的第一印象是“做过科研、进入过多个真实科研场景、能力逐步增加”，而不是主动把自己删成一张很薄的简历。

本轮采用的原则是：

> **提高证据密度，不提高包装强度。**

即：增加真实条目和真实上下文，但每个条目的贡献强弱仍明确区分；署名不等于贡献，项目级别不等于获奖，事后读懂论文也不改变当时的真实分工。

## 2. 主要改动

### 2.1 增加国家级大创，但放在“科研经历”，不放“精选荣誉”

新增：

- 国家级大学生创新创业训练计划；
- 平台项目名：`磁性纳米合金-石墨烯复合型吸波材料制备与性能研究`；
- 项目编号：`202410213227`；
- 身份只写“项目成员”；
- 只写已确认的实际贡献：数据处理与可视化、部分论文图件制作及稿件文字工作。

**为什么不放奖项栏：** 国家级大创首先是科研训练项目，不是竞赛奖项。把它放进“荣誉/奖项”虽然视觉上更像加分项，但分类不准确；放在科研经历里反而更有价值，因为它能够证明申请人并非只有一次毕设，而是本科阶段持续进入过材料/电磁相关研究和论文协作流程。

**边界：** 现有证据支持国家级平台、编号、本人列名；平台题名与 2024-12 结题证书、培育验收书题名不同，因此本版**不写“国家级已结题”**，也不把不同题名证据强行拼成同一项目的完整结题链。

### 2.2 论文从“精选两篇”改为“论文发表三篇”

新增第三篇共同作者论文：

Zeyang Zhang, Jun Li, Juan Cui, Zegeng Chen, Zhengyu Zhang, Nandong Deng, Yulin Zeng, **Zijing Zhou**, Zhongxiang Zhou. *Broadband Microwave Absorption of Nb2CTx Nanosheets by a One-Step Hydrothermal Method*. Inorganic Chemistry, 2025, 64(19): 9435–9446. DOI: 10.1021/acs.inorgchem.4c05411.

本轮书目信息已按出版方提交的Crossref DOI记录复核，申请人为第8位作者；ACS页面本次返回403，未声称取得全文。见[原响应与事实核验](../事实核验/PR8审查_20260928/事实核验.md)。

**为什么建议列出：** Publications 栏首先陈列客观作者身份。只要作者身份真实，完整 CV 列出该论文并不等于声称本人承担了核心研究。此前完全删除它，会让第一眼成果密度降低，也会使“完整论文发表记录”与系统未来要求的全量清单不一致。

**为什么不在第三篇下面写贡献：** 当前事实库将该论文记录为低参与/名义共同作者，尚没有足够证据支持具体、可核的个人科研贡献。因此候选 CV 只列书目信息，**不写实验、数据、分析、写作等贡献**。后续做科研经历全面梳理时，如果本人能从原始记录确认当时确实承担过具体文字、图件或其他工作，再按事实补一句；如果确认几乎没有实质工作，就维持“只列论文、不展开贡献”。

**重要边界：** 现在重新精读这篇论文是必要的，目的是保证申请人至少能解释论文研究问题、方法、主要结果以及自己当时实际做了什么；但“现在学懂”不能倒推成“当时做过”。

### 2.3 两篇真正有贡献的合作论文继续明确个人分工

- 吸波材料论文：数据处理与可视化、部分图件、稿件撰写；
- 尘埃等离子体论文：MATLAB 模拟数据处理、偏振特征分析、粒子运动轨迹可视化。

这两个 contribution 说明的作用，是主动告诉 PI：论文作者顺序不能直接代表全部工作，但申请人能够准确说清自己承担的部分。它们与第三篇“只列书目、不展开贡献”形成清晰层级，避免把三篇论文包装成同一 ownership 水平。

### 2.4 保留本科毕设为绝对主轴

毕设仍占科研区最大的篇幅，三条结构保留；Work将旧“构建分阶段搜索流程”同步为后续已核的“调整分阶段搜索流程”：

1. Python-CST 自动化；
2. 参数空间扩展、GA 搜索与几何约束筛选；
3. 薄实体膜 / Ohmic Sheet 建模比较与结果分析。

理由：当前申请人最完整的 ownership 证据仍是本科毕设。CV 增密不能把“条目多”做成视觉主轴；正确层级应当是：

> **毕设（最完整闭环） > 两段真实合作研究/项目 > 第三篇低贡献共同作者论文。**

### 2.5 同步更新四年排名口径

旧 Master v1.2 仍保留“2025.09 推免口径”的历史表达。本轮已有 2026-09-28 校方四年专业排名证明，支持 2022 秋—2026 春 `21/46`。

候选版因此改为正文：

`算术均分：80.20/100*｜专业排名：21/46`

并在页脚说明：

- 80.20 是依据 91 门百分制课程自行计算的算术平均，不是 GPA；
- 21/46 来自四年专业排名证明；
- 不把校方考试课平均学分绩 73.58 与 80.20 混为同一口径。

## 3. 这版 CV 想形成的第一眼叙事

不是：

> 三篇论文 + 国家级项目 = 科研很强。

而是：

> 本科阶段持续进入过多个真实科研场景：材料/电磁项目中做过数据、图件和稿件协作；尘埃等离子体项目中承担过 MATLAB 数值数据处理和可视化；到本科毕设阶段，开始承担更完整的参数化建模、自动仿真、搜索和结果分析流程。已有三篇共同作者论文，但不同论文的实际贡献强弱明确区分。

这能够把当前最真实的申请人画像表达出来：

- 不是“独立一作型成熟申请人”；
- 也不是“只有挂名论文、没有真正做过科研”；
- 更接近“经历过多种真实科研工作，ownership 在毕设阶段明显增加，具备可训练性和计算/数据工作入口”。

## 4. 为什么这比单纯堆条目更安全

本版没有做以下事情：

- 不把国家级大创写成国家级奖项；
- 不写“国家级已结题”；
- 不把大创与吸波论文强行写成确定的立项→结题→论文因果链；
- 不给第三篇论文补造个人贡献；
- 不把 CST 写成 FEM 理论能力；
- 不写“开发遗传算法”；
- 不增加 DFT/MD/PyTorch/GNN/HPC 等未掌握技能；
- 不把三篇共同作者论文写成三项独立主持成果。

因此增密来自**真实科研证据的完整展示**，而不是措辞升级。

## 5. 对一页版式的意见

目标仍建议维持 **1 页 cold-email CV**。但优先级应当是：

1. 先保留毕设完整三 bullet；
2. 保留国家级大创一条紧凑贡献；
3. 保留晶格波两条；
4. 保留三篇论文书目信息；
5. 若版面超出，再压缩荣誉、技能行距和论文排版，而不是先删除真实科研资产。

第三篇不增加contribution行。原提案对新增篇幅的预估偏少：Work实排为3行完整书目+1行DOI；国家级大创为标题、成员/编号/导师行及1条贡献。通过技能和荣誉合并、段距/行距调整保持一页，正文仍10.5 pt。

不建议为了强行一页把正文压到明显影响阅读的字号。如果合理压缩后仍无法一页，应由 Work 在实际 Word/PDF 版式中比较“紧凑一页”和“舒适两页”后给出建议，但首轮 PI 套磁仍优先一页。

## 6. Work 合并前请重点审查

1. **国家级大创证据边界**：核对平台项目名、项目号、本人列名；确认没有出现“已结题”“负责人”“主导实验”等越界措辞。
2. **第三篇论文书目**：核对 DOI、作者顺序、期刊卷期页码；不新增未经确认的个人 contribution。
3. **排名**：以 2026-09-28 四年排名证明覆盖旧推免口径表达；80.20 继续明确为自算算术均分而非 GPA。
4. **版式**：基于现有 Master v1.2 Word 版式生成新的候选 Word/PDF，检查是否仍可自然保持一页；不要覆盖 v1.2。
5. **版本状态**：本 PR 的 v0.6 只是 INTERNAL 编辑源，拟生成的 Master v1.3 在本人终读前只能是 CANDIDATE；**不得因为合并 PR 自动变成 READY，更不得改写刘癸庚已发送的 CV v4。**
6. **完整科研梳理接口**：后续对全部研究经历按“研究问题 / 我实际做了什么 / 我没做什么 / 输出 / 学到什么 / 可被追问的问题”复盘；第三篇只有在原始记录支持时才补具体贡献。

## 7. 建议的版本关系

- `Master v1.2`：继续保留为最后一个已冻结 READY 公共版本，历史状态不追改；
- `v0.6 INTERNAL`：本 PR 新增的编辑源；
- `Master v1.3 CANDIDATE`：由 Work 审核内容并生成 Word/PDF 后建立；
- 本人完成 PDF 终读并明确确认后，才能升级为 `Master v1.3 READY`。

这一关系可以保证“我们主动增强 CV 第一眼科研密度”和“已冻结、已发送材料不得被静默覆盖”同时成立。
