# 跨路线公共事实与材料索引

更新：2026-09-27 | INTERNAL 导航 | 适用于 A–E 五线；不是新的事实副本或投递包。

## 使用规则

原件、事实核验、冻结材料和历史快照各保留在原路径。本页只确定入口及使用边界；跨路线共用同一个已核实事实，不共用 eligibility、项目要求、联系状态或提交事件。申请规则仍在相应路线/项目核验。

发生冲突时，按对应字段的较新证据和用户确认查核；较新的材料文件名或旧邮件不自动推翻原件。待核仍为待核。发现新证据后在现行事实源追加可追溯更新；冻结 CV/已发送材料不覆盖，需要变更则另立版本。Research Defense 中的 APPLICATION 副本是历史快照，不替代现行母版，也不证明本人已完成学习。

## 渐进迁移约定

1. **本 PR：** 只建立本索引并接入各路线入口；事实源、CV、原件、Defense 和状态表均不迁移。
2. **以后出现真实维护需求时：** 新增共享专题可放入 `00_Common/Applicant_Profile` 或 `00_Common/Shared_Materials`；先指定唯一维护源，再从各线引用，不把同一事实抄成多个可编辑版本。
3. **确需移动现有非原件文件时：** 逐个专题处理，先列入站链接、版本/状态和哈希；验收新位置与链接后，旧入口保留指向说明，记录旧/新路径及哈希。遵守同级历史版本规则，不搬原 20 件，不覆盖冻结/已发送/已提交文件，历史快照不改写。

暂不建立数据库，不批量重命名 `A线工作区`，不复制出第二套 CV Master。是否进一步迁移取决于实际重复维护负担，不作为 PR #3 合并前置条件。
