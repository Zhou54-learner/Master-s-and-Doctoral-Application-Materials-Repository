私人申请工作区，按本人授权同步至本私有仓库。当前申请入口：[A线工作台](A线_工作台.md)；事实与操作约定：[AGENTS.md](AGENTS.md)。

## 同步范围

- 保存当前目录内的非压缩包文件，包括原始材料、历史版本、研究代码、证据记录及已有运行依赖。
- 按本人确认，36份 ZIP 压缩包仅保留本地，不上传；`.gitignore` 中的 `*.zip` 适用于后续 ZIP。仓库不是完整科研源快照备份，文档中引用的 ZIP 仍须从原本地目录取得。
- Git 不记录空目录。外部路径（如 `F:/biyesheji`、`E:/2024`）仅有已经复制到本目录的内容进入此次同步。
- `07_Research_Defense/98_Archive_Records/F_biyesheji_temp.csv` 使用 Git LFS（218,364,729字节）。其他文件直接由 Git 保存。
- `.gitattributes` 禁用自动换行转换，保持原件与历史证据的字节一致性。

## 获取与继续工作

克隆前安装 Git LFS，克隆后执行 `git lfs pull` 获取大文件正文。不要把 LFS 指针当作完整 CSV。

后续按独立任务创建分支；每次开始前先读工作台与接续约定，每次完成后提交明确范围的变更。已发送材料、原始证据和历史版本的保留规则继续适用。启用版本管理不代表已经开始其他申请线，也不代表已发邮件或提交申请。

本仓库包含私人材料，须保持私有；此次授权仅针对指定仓库。
