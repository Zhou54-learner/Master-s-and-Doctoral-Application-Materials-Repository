## 1. 路线目标

将香港科技大学（广州）PhD 与香港中文大学（深圳）PhD 合并为一条大湾区直接博士路线管理。

两校在本路线内并列，不预设优先级；后续按项目、PI、funding 和真实回复比较。

本路线当前明确采用：

> **多投宽投 + 录取可能性优先 + 培养质量底线 + 方向本人可接受**

强组/明星组保留为上行机会，但不承担主要录取概率。重点寻找 `under-demanded but good`：新组、扩组、明确招 PhD、学生来源宽、愿意训练跨方向学生的 PI。

## 2. 核心筛选维度

学校/项目层：
- 当前本科背景是否满足 2027 直接 PhD 申请资格；
- 具体学科/项目是否允许本科起点申请；
- full-time PhD 的 funding、tuition waiver、stipend；
- 导师绑定与转组机制；
- 培养年限、课程与资格考试；
- 学位授予主体与未来国内外认可。

PI 层新增：
- 入职时间 / 组龄 / 是否扩组；
- 2027 实际招生信号；
- bachelor-entry PhD 历史；
- 学生本科/硕士来源与入组前科研强度；
- RA / visiting / thesis → PhD 路径；
- 是否把一作/顶刊设为前置；
- 是否愿意从 physics / simulation 基础训练新方法；
- 本人现有 CST/Python/MATLAB 能否形成即时入组价值。

## 3. 优先方向

优先寻找：

- Computational Physics
- Condensed Matter / Materials Physics
- Computational Materials
- Scientific Computing / Numerical PDE / wave simulation
- Photonics / Electromagnetics / metamaterials / inverse design
- Device modelling / multiphysics simulation
- AI for Materials / Scientific ML / AI4Science（不因标签本身升优先级）
- 物理问题驱动的 data-driven / computational research

避免仅因“AI”标签进入纯 benchmark / 纯工程模型路线；申请叙事仍以真实物理问题和计算科研能力迁移为中心。
