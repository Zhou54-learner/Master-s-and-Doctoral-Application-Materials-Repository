## 分层说明

- **P0｜概率优先主力**：当前招生信号、组龄/扩张状态、学生门槛与本人背景综合看来值得优先联系。

## 当前筛选原则

1. 优先年轻 PI、小组、扩招组和明确招生页；
2. 看学生入组前背景，而不是只看导师论文与名气；
3. 允许从 EM simulation 向 scientific computing、device modelling、computational materials 等相邻方向迁移；
4. 热门强组占少数，用于上行，不承担主路径；
5. 后续根据真实回复率迭代分层。
