## 3. 已确定的申请策略

### 核心不是“找最强/最匹配 PI”

本人的简历是典型 **纸面指标不均衡、真实项目能力强于 GPA/论文标签** 的 profile。

因此目标函数为：

> **录取可能性优先 × 培养质量过线 × 方向本人可接受**

而不是：

> PI 名气 × 关键词匹配度

### 池子结构

建议最终联系池大致：

- 15–20%：强组/热门组/高度匹配的上行机会；
- 50–60%：现实主力组；
- 25–30%：概率优先组（新组、扩组、明确招人、方向相对冷门但训练靠谱）。

优先寻找 `under-demanded but good`，不是 low-quality group。

### 特别关注的录取友好 proxy

1. 新入职 1–5 年、正在扩组；
2. 当前明确招 PhD / RA / MPhil；
3. 学生本科来源分布宽；
4. 历史上有 bachelor-entry PhD；
5. 愿意通过 RA / visiting / thesis project 观察学生再转 PhD；
6. 学生要求没有把一作/顶刊设为硬前置；
7. 愿意训练跨方向学生；
8. 本人现有 simulation / coding 能直接成为入组价值。
