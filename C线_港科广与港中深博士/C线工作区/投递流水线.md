## 2. 与 A 线一致的核心纪律

1. **事实先于文案**：每位 PI 先核当年招生/组状态/研究桥梁，再写邮件。
2. **公共材料冻结，PI 包只做必要定制**：不为每位导师重写整份经历。
3. **状态唯一维护**：外部联系事件只在本文件的联系队列中记；准备材料不等于发送。
4. **人工终审**：邮件和附件在升级 READY 前做事实、措辞、收件地址、附件一致性核对。
5. **用户发送锁**：任何邮件必须由用户对该封邮件明确确认“可以发”后才能发送。连接 Gmail 不等于授权。
6. **不补写不存在的事实**：不夸大 GA、AI4Science、DFT/ML；不把组扩张 proxy 写成“容易录”。
7. **真实回复优先更新判断**：网页 proxy 的 P0/P1/S/E 可被回复/面试结果覆盖。

## 4. 推荐流水线方式

### 4.1 准备方式
- 每批同时准备 **HKUST(GZ) 4–5 位 + CUHK-Shenzhen 4–5 位**。
- 同一公共英文 CV / transcript 基线复用；只在确有必要时做 PI-specific CV 微调。
- 首封长度控制在可快速阅读范围，通常三段核心：本人/申请目标 → 已完成研究能力 → 为什么这个组 + 一个明确问题。
- 首封默认附件：英文 CV + 本科成绩单；论文全文除 PI 页面明确要求外不默认堆附件。

### 4.2 发送方式
- 可以在同一周内并行发送多位 PI；**不要求一位回复后才联系下一位**。
- 每封仍须用户逐封明确授权。
- 不同学校/组之间不提其他申请对象。

### 4.3 等待与复评
- 发送后第 3 个自然日：只做一次状态评估，不自动催信。
- 7–10 天无回复：视 PI 招聘页面、优先级和是否有新增信息决定是否 follow-up 1 次。
- follow-up 仍需用户确认；原则上最多 1 次。
- 明确无名额后立即归为 `CAPACITY_REJECTION`，释放精力给下一位。
