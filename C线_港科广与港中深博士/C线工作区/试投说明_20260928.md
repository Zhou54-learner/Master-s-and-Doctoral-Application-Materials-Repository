# C线首轮试投说明｜2026-09-28

## 目的

本轮不是选择“最强 PI”，而是用两封低成本、高信息量套磁测试真实市场反馈：

1. HKUST(GZ)：测试 bachelor-entry + EM simulation / photonics 迁移是否被新组接受；
2. CUHK-Shenzhen：测试 commercial EM solver + automation 背景能否被 scientific computing / numerical wave PI 认可为博士训练起点。

## 首轮对象

- HKUST(GZ)：许泽锋 Zefeng Xu
- CUHK-Shenzhen：龚世华 Shihua Gong

## 结果更新规则

- 无回复：7–10 天后视情况 follow-up 1 次；不能单独解释为背景不够。
- 明确无名额：记录为 capacity rejection，不下调本人能力判断。
- 表示欢迎正式申请：弱正信号。
- 索要项目材料 / 要求交流：中等正信号。
- 安排技术面试 / RA / project discussion：强正信号，并据此扩大相似 PI 池。

## 当前纪律

- 语言成绩暂不作为首轮联系前置；如 PI 明确表现兴趣或要求正式申请，再立即启动 IELTS 计划。
- 不夸大 GA、AI4Science、DFT/ML 经验；只陈述已完成的 CST/Python/GA workflow、MATLAB 数据分析和合作论文。
- 第一批回复结果将反向更新 P0/P1/S 分层，而不是继续仅靠网页信息估计录取概率。
