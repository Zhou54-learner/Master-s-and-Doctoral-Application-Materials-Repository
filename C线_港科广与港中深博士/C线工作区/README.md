## 当前原则

- 目标函数：**录取可能性优先、培养质量过线、方向本人可接受**；
- 强组/明星组只承担上行，不承担主要 offer 概率；
- 主体寻找 `under-demanded but good`：新组、扩组、明确招人、学生背景宽、Bachelor-entry 友好、没有强论文硬前置；
- P0/P1/S/E 是资源分配标签，不是导师质量排名或录取率；
- 真实回复优先于网页 proxy；
- 西湖 A 线由另一会话维护，本工作区不重复操作 A 线。

## 双校串行发送规则

- HKUST(GZ) 与 CUHK-Shenzhen 两条队列彼此独立；
- 同一学校两封首封至少间隔 3 个自然日；
- 每个 3 天周期内，同校只新增 1 位首封对象；
- 后续材料可以提前准备，但不能提前发送；
- 第 3 天只做状态评估，不自动催信；
- 7–10 天后才考虑唯一一次 follow-up；
- 实际发送日决定下一封的最早日期，不按最初时间表“追赶”。

详见：`双校串行投递时间表_20260929.md`。

## 英文外发包与中文审查镜像

- 中文不得独立优化；任何修改先落到英文，再同步中文。
- 英文版本一旦修改，旧中文镜像立即视为过期。
