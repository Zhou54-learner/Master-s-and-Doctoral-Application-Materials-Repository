# C线中文审查镜像规则

更新：2026-09-29

## 目的

C线所有正式对外联系材料以**英文外发版本**为唯一 canonical source；中文版本仅作为本人审阅用的 `REVIEW MIRROR`。

中文审查镜像的目标是让本人能够用中文快速检查：

- 事实是否准确；
- 研究叙事是否符合真实经历；
- 对 PI 的研究理解是否恰当；
- 是否存在过度包装、自我削弱或群发模板感；
- 邮件最后的问题是否清楚；
- CV 每一项事实、贡献和能力边界是否合适。

## 强制规则

1. **英文是唯一外发版本。** 中文镜像不得发送给 PI，不得上传申请系统。
2. **中文不得自由改写。** 必须逐项映射对应英文版本的含义、结构和信息量，不得在中文里增加、删除或修正事实。
3. 每个中文镜像必须注明其对应的英文源文件与版本。
4. 英文邮件、CV、research statement 或附件说明一旦发生实质修改，对应中文镜像自动视为 `STALE`，必须同步后才能继续审阅。
5. 中文审查中提出的修改建议，先修改英文 canonical source，再重新生成中文镜像；不要只改中文。
6. 中文镜像与英文原文若含义冲突，以英文 canonical source 为准，并立即修复中文镜像。
7. 中文审查包不改变任何联系状态；`READY_REVIEW`、`USER_APPROVED`、`SENT` 等状态只由英文正式包和真实发送事件决定。
