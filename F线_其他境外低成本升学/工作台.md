## 1. 路线定位

本路线管理**香港特别行政区之外**的低净成本境外升学机会，与 E 线香港研究型学位池正式分离。

路线对象不限于硕士，可包括：

1. admission-linked funded PhD / project PhD；
2. funded MPhil / research master；
3. 低学费且 research/thesis 明确的 MSc / Master；
4. 需要额外竞争的全奖/高额奖学金硕士；
5. KAUST 等录取即 funding 的特殊学位路径；
6. 必要时的 6–12 个月 RA / predoc bridge。

本路线不把“国外”或“免学费”本身视为价值；核心仍是科研训练、净成本、平台增益和未来选择权。

## 2. 用户预算与资金规则

- 若学习期间可以通过 stipend / 合规兼职覆盖部分生活，家庭总净支出原则上不超过人民币 8 万元；
- 若必须冻结/占用现金，原则上不超过人民币 10 万元；
- 可接受一年 RA 换更高平台；
- 无明确地域排除，毕业后可能留当地工作生活。

### Funding Gate

- **A FULL / SALARIED**：正常学制 tuition covered / waived，stipend/salary 可覆盖主要生活；优先。
- **B CONDITIONAL FUNDING**：奖学金/PI funding 与 admission 分离或二次竞争；可留，但不能作为预算已通过。
- **C LOW-TUITION / LOW-COST**：无完整 stipend，但 tuition 低、research value 高；只保留少量硕士/bridge。
- **D SELF-FUNDED / HIGH-COST**：高额自费且无明确资助；主池剔除。

任何需要单独竞争奖学金才能满足预算的项目，必须分开记录：Admission chance、Funding type、Funding probability、Cost without funding、Cost with funding、Cash requirement、Final budget verdict。

`scholarship exists ≠ scholarship realistically attainable`。

## 3. Geo / Research-Security Gate

由于申请人本科为 Harbin Institute of Technology，F 线正式加入第三道硬 Gate：

> **Funding Gate → Eligibility Gate → Geo/Security Gate**

- Canada：HIT 当前在 Named Research Organizations 名单中；历史学历本身不是 admission ban，但 specific federally funded sensitive-technology projects 需核 current affiliation / support 与 STRAC。
- United States：未来新增项目默认 `HOLD-HIGH`，先核 PP10043 / BIS Entity List / visa / lab access。
- 其他地区：目前未发现因 HIT 历史学历形成统一 blanket ban，但所有敏感技术 / dual-use project 均需项目级检查。

详见 [`政治与研究安全风险Gate.md`](政治与研究安全风险Gate.md)。

## 5. 当前策略结论

### 5.1 三种值得保留的结构

1. **少数 bachelor-entry fully funded PhD / special graduate school**：ISTA、OIST，以及选择性的新加坡路径。
2. **加拿大 funded thesis MSc**：UBC / McGill / McMaster funding 结构非常好，但第二轮确认其 academic competition 不应低估；它们是高价值 P1，不是 probability-priority。
3. **德国低学费 research MSc**：Paderborn / Greifswald / Osnabrück / HHU / Saarland / Jena 等承担 probability/value layer 和研究训练跳板。

### 5.2 F-1 第二轮后的关键修正

第一轮“加拿大 funded MSc = 主力概率层”的表达现修正为：

> **加拿大 funded MSc 是高价值主力申请层，但不是概率层；当前成绩结构下，真正承担 P0 / probability-value layer 的仍应是德国一组 low-cost research MSc。**

具体：
- UBC：中国学历一般约 85% 门槛，但 211 applicant 可按 80% minimum；HIT 使约 80.2/100 达制度最低附近，但竞争风险仍高。
- McMaster：最低 final-year B+，官方称实际被录取者通常 A- 或更高；funding 很好但不能当保底。
- McGill：制度可申、funding 清楚，但当前成绩同样没有明显余量。
- Greifswald：第二轮价值上升，dusty/colloidal plasma、computational science、soft matter 与 applicant 已有合作研究存在罕见的真实直接迁移入口。

### 5.3 不应误判的制度

- 欧洲 salaried PhD 工资很好，但 Germany / France / Belgium / Netherlands / Switzerland / Nordics 大量岗位默认 master-entry；当前 bachelor 不应把它们当 2027 主池。
- Australia / New Zealand HDR scholarship 很强，但 honours/research-equivalence gate 对当前学历和成绩结构存在明显风险，先 HOLD。
- KAUST 全部 graduate admission funding 很强，但当前普通 PhD 需要 relevant master；本科应看 MS / 可用的 MS/PhD pathway，不误投 AP direct PhD。

## 7. 第二轮执行队列

### F-1A｜德国 PI / thesis ecosystem
顺序：**Greifswald → HHU Düsseldorf → Paderborn → Osnabrück**。

逐组核：
- master student 是否真实进入；
- 近年 thesis topics；
- 方法训练（实验/数值/理论）；
- HiWi / research assistant opportunity；
- PhD transition；
- security / dual-use risk。
