## 1. 路线定位

本路线管理**香港特别行政区之外**的低净成本境外升学机会，与 E 线香港研究型学位池正式分离。

路线对象不限于硕士，可包括：

1. admission-linked funded PhD / project PhD；
2. funded MPhil / research master；
3. 低学费且 research/thesis 明确的 MSc / Master；
4. 需要额外竞争的全奖/高额奖学金硕士；
5. KAUST 等录取即 funding 的特殊学位路径；
6. 必要时的 6–12 个月 RA / predoc bridge。

本路线不把“国外”或“免学费”本身视为价值；核心仍是科研训练、净成本、平台增益和未来选择权。

## 2. 用户预算与资金规则

- 若学习期间可以通过 stipend / 合规兼职覆盖部分生活，家庭总净支出原则上不超过人民币 8 万元；
- 若必须冻结/占用现金，原则上不超过人民币 10 万元；
- 可接受一年 RA 换更高平台；
- 无明确地域排除，毕业后可能留当地工作生活。

### Funding Gate

- **A FULL / SALARIED**：正常学制 tuition covered / waived，stipend/salary 可覆盖主要生活；优先。
- **B CONDITIONAL FUNDING**：奖学金/PI funding 与 admission 分离或二次竞争；可留，但不能作为预算已通过。
- **C LOW-TUITION / LOW-COST**：无完整 stipend，但 tuition 低、research value 高；只保留少量硕士/bridge。
- **D SELF-FUNDED / HIGH-COST**：高额自费且无明确资助；主池剔除。

任何需要单独竞争奖学金才能满足预算的项目，必须分开记录：Admission chance、Funding type、Funding probability、Cost without funding、Cost with funding、Cash requirement、Final budget verdict。

`scholarship exists ≠ scholarship realistically attainable`。

## 4. 第一轮得到的策略结论

### 4.1 当前最值得的三种结构

1. **少数 bachelor-entry fully funded PhD / special graduate school**：ISTA、OIST，以及选择性的新加坡路径。
2. **加拿大 funded thesis MSc**：UBC / McGill / McMaster 等，是本轮发现的高价值主力层；比“低学费但无 stipend”更符合 F 线经济纪律。
3. **德国低学费 research MSc**：Paderborn / Greifswald / Osnabrück / HHU / Saarland / Jena 等，作为 probability layer 和研究训练跳板。

### 4.2 不应误判的制度

- 欧洲 salaried PhD 工资很好，但 Germany / France / Belgium / Netherlands / Switzerland / Nordics 大量岗位默认 master-entry；当前 bachelor 不应把它们当 2027 主池。
- Australia / New Zealand HDR scholarship 很强，但 honours/research-equivalence gate 对当前学历和成绩结构存在明显风险，先 HOLD。
- KAUST 全部 graduate admission funding 很强，但当前普通 PhD 需要 relevant master；本科应看 MS / 可用的 MS/PhD pathway，不误投 AP direct PhD。
