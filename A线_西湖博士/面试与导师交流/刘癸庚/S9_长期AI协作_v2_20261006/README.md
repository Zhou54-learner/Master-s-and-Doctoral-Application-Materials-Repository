## 制作源

已安装环境：Python 3.11、python-pptx、Pillow、pywin32；实际导出需要本机PowerPoint 16.0。Poppler仅用于已导出PDF的检查。

```text
python 制作源/build_slides.py
python 制作源/render_pair.py --only s9
python 制作源/review_sequence.py
python 制作源/preserve.py check
```

主图输入副本在`制作源/输入/`，记录原图SHA-256；原公共素材只读。`render_pair.py --only s8`可对同轮S8新候选导出。`preserve.py freeze`是本轮接手基线采集入口，存在基线时拒绝覆盖，不应重新冻结冒充原状态。脚本只能生成本轮候选与审阅图，不调用旧builder；冻结后的后续修改须另建版本。
