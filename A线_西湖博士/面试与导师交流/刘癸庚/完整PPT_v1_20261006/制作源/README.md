# 制作与验收入口

本目录只构建本轮选定的完整版本，不调用科研优化器或旧单页制作脚本。

1. `merge_lossless.py` 从指定 11 份 PPTX 复制页面及资源，独立保留 S2–S5 页面母版；只清理 5 页的交付状态文字，将指定 v3 讲稿逐页写入备注。所有输入逐字节对照构建时当前 HEAD。
2. `render_and_check.py` 通过 Microsoft PowerPoint 16.0 只读打开、导出 PDF/PNG，读回备注，检查文字、对象、图片比例，并把来源页面与整套页面逐像素比较。状态文字区域外要求完全一致；S7 同时另存本轮来源 PDF 供复核。
3. `finalize_delivery.py` 核验包内关系、备注、PDF、PNG、源件保全，并生成映射、报告和交付清单。

运行环境见 [运行环境.json](运行环境.json)。构建入口拒绝覆盖已存在的成品；如需修订，复制为下一个明确版本并更新输出名，原交付继续保留。PDF 默认不含讲稿，备注位于 PPTX 与逐页文本。
