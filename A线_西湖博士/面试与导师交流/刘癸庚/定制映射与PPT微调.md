# 刘癸庚｜定制映射与 PPT 微调

状态：INTERNAL｜最终 PPT 前置工作页

刘老师当前明确要求是：**准备一个 PPT，介绍自己的工作。** 因此本场定制的第一原则是：科研本身优先于“Why this group”包装。

## 一、公共母版如何调整

建议比田老师版本更偏 Research Defense：

1. 个人背景：1页以内；
2. 本科毕设：2–3页，作为绝对主线；
3. 其他科研：1页；
4. 工作方法 / 技能迁移：1页；
5. 未来兴趣 / 与复杂波研究的连接：1页；
6. 备用页：模型、GA、结果图、贡献说明、可靠性等。

具体页数待排期和交流时长确认后调整。

## 二、本科毕设需要特别加强

刘老师方向与电磁 / 波动问题接口较强，因此准备时重点做到：

- 不只说“用了 CST”；能解释模型求解的物理问题；
- 参数空间、fitness 与 GA 搜索逻辑讲清楚；
- 为什么增加某些几何 / 片阻自由度；
- 为什么需要连通性等约束；
- 薄实体膜与 Ohmic Sheet 的物理 / 建模差异；
- 反射结果的口径与未完成的全端口功率、收敛验证；
- 最真实的调试 / 失败案例。

## 三、PI-specific 连接候选

待核心论文学习后再定稿。当前只保留逻辑：

> 已有工作让我熟悉频域电磁结构、参数化仿真、自动化和受约束搜索；希望把这些基础迁移到更强调波动物理机制的问题中，并系统补足拓扑 / 非厄米等理论以及相应实验方法。

不能把“会电磁仿真”直接写成“适合拓扑 / 非厄米研究”。

## 四、刘老师特有追问池

后续重点准备：
- 你认为自己的毕设里最核心的物理问题是什么？
- CST 实际在解什么？边界条件怎么设？
- GA 为什么比普通扫参更合适？有没有 baseline？
- 你如何判断优化结果不是偶然？
- 你对 periodic / mode / band / topology 有什么理解？
- 为什么希望从应用型电磁结构进一步做复杂波物理？
- 是否愿意做理论推导 / 实验，而不是只做数值优化？

## 五、反问方向

排期确认后再选 2–3 个：
- 新入组本科直博生通常如何确定最初课题？
- 理论 / 数值 / 实验在学生项目中通常如何分配？
- 对已有电磁仿真背景、但拓扑 / 非厄米训练不足的学生，前期通常如何进入问题？
- 日常指导由 PI、博士后或高年级学生如何协作？

不要第一次交流就把所有培养制度问题逐项盘问。

## 六、最终 Gate

先通过[公共输出规范](../../../公共资料/面试与导师交流中心/公共主干/面试资料母版与输出规范.md)，再检查：
