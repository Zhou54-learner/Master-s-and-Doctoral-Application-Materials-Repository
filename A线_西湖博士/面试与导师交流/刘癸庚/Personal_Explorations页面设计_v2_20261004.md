# 个人探索｜逐页设计 v2

2026-10-04｜INTERNAL / DESIGN REVIEW｜PR #15；本轮仍不制作最终 PPT。

**改为五个主题页，每页一个主画面，总计约 85 秒。** 本人看过 v1 后认为太挤、图片展示不清、内容不好介绍，并明确选择放宽至 80–90 秒。本轮据此放弃“一页四模块”的主设计，整场内部预算调整至约 9 分钟。

[打开可翻页预览](Personal_Explorations逐页预览_v2_20261004.html)；左右方向键翻页，第三页点击“知识地图 / 执行驾驶舱”或按空格切换画面。它只检验信息架构和展示尺度，不是最终 PPT。

## 1. 这次改动解决什么

v1 的问题不是文字溢出，而是**四组截图在同一时刻争夺注意力，原图里的结构和内容被缩小到无法用于讲解**。“排得下”没有达到“看得清、讲得顺”的要求。这次不再用更多裁切去勉强保住一页。

- 一次只让老师看一个主题；标题说清这页的意义，图占主要空间。
- 五个主题依次是乐音、物理学习 Agent、考研学习系统、公众号、个人艺术网页。后两项分开呈现，叙事上仍属于“写作与表达”。
- 同一条成长线保持：自主研究一个小问题 → 做工具并复盘 → 组织长期学习 → 形成文字与视觉表达。页数增多，不增加项目或成果主张。
- 学习系统有两张高价值图，**同一页先后展示**，不再左右拼小。最终 PPT 可用原位切换；如果实现不可靠，用两张连续演示帧承接同一主题，合计时长不变，不另写第二段介绍。
- 中文为主；沿用本人原图和历史结果，不生成界面、实验曲线或新项目。

## 3. 中文逐页讲稿

### P1｜约 22 秒

> 正式科研之外，我也习惯把感兴趣的问题做成小项目。大二参加物理实验竞赛时，我第一次自主推进乐音研究，从录音入手，比较不同管尺寸下的频率特征。这里是当时保存的波形和频谱：声音变成了可以分析的数据。

讲到“波形和频谱”时指向上下两图，不再解释完整曲线或算法。研究意义落在第一次走过数据分析过程；关于峰与模态的区别留作问答。

### P2｜约 20 秒

> 后来，我第一次比较系统地尝试和 Agent 协作，做一个物理学习工具。回头看，这个原型有过度设计和重复造轮子的问题。更有价值的收获，是围绕人和 Agent 怎样协作、工作流怎样组织，积累了一批经验和复盘材料。

画面证明真实原型存在，口述解释从原型到方法的转变。S01 经验资产目录留在备用素材中，被问到时才打开；不因为页数增加就把它重新塞回主画面。

### P3｜约 20 秒

> 接着，我把这些尝试放进考研学习流程。知识地图用来组织要学什么和当前状态，执行驾驶舱则把材料、任务和通过条件放在一起。我想尝试的是，让 AI 不只回答一次问题，而是帮助学习过程持续接续。

前半段展示地图；说“执行驾驶舱”时切图。两张画面只解释同一个问题：怎样从“知道学什么”走到“下一步怎么做”。不逐个读课程节点、具体日期或状态记录。

### P4｜约 11 秒

> 我也在“无用清净梦”里整理对 AI、学习和工作的思考。比如这篇提出的问题：当完成任务越来越不需要人，工作还意味着什么？

这一页只用一个真实选题让写作变得具体；不介绍文章数量、阅读量或整篇论证。对 AI 对话内容的使用保留真实边界。

### P5｜约 12 秒

> 网页是另一种表达方式。这是个人艺术网页里可以实际点入的第三个板块。我也尝试把想法组织成文字和视觉，让思考有一个具体的表达形式。

HUMAN+ 画面只作为个人艺术网页的真实板块；不逐项推销画面中的服务，不把它说成网站总首页或成熟产品。随后回到未来方向页。

口述约357个汉字，另含少量英文术语；五页换页与看图停顿计入85秒预算。这些是口述草稿而非已经完成的本人排练记录。先按自然语速录一遍，目标 80–90 秒；如果超过 90 秒，先缩短 P1 开场和 P5 收束，不压缩看图停顿。若老师插问，转入交流，不抢读剩余稿。

## 4. 图片来源与事实边界不因拆页变化

来源唯一清单与检查依据仍见[公共核验记录](../../../公共资料/事实核验/个人探索_20261004/核验记录.md)及[来源清单](../../../公共资料/事实核验/个人探索_20261004/来源清单.json)。本轮不新增个人事实，不改历史研究文件。

主讲原图仍为 M01、S02、S06、S05、S03、S08；只是从一页组合改为逐页展示。S01 经验资产、S04 状态详情、M02/M03 尺寸比较图仍备用；S07 与 S06 完全重复，不展示两次。远端压缩包的编号 07 与本会话 S07 不同，不混用。

仍须保留的 UNKNOWN：FFT 原始生成脚本、实验边界与激励、细分团队/代码分工、主峰的基频/模态归属，Agent 文档具体内容和学习效果，人/AI 在具体文章及网页中的细分贡献。现存音高代码是 NCF；历史频谱可见，但不改口声称已核到 FFT 实现。S08 归属已由本人确认，非 UNKNOWN。

每页最多主动讲一个解释；实验细节、过度设计实例、学习状态判定、人—AI 分工和网页表达意图，仍留作被问到时展开。展示更清楚不等于增加能力承诺。

## 5. 整场时间重新对齐

本人本轮已选 80–90 秒。按中值 85 秒替换 v1 的 55 秒，整场由 8:30 调整到 **9:00**，不削减毕设主线：

| 环节 | 预算 |
|---|---:|
| 背景与科研入口 | 0:35 |
| 本科毕设核心 | 4:45 |
| 偏振/合作科研 | 0:55 |
| 个人探索五页（含内部换页与切图） | 1:25 |
| 未来方向与刘老师连接 | 0:50 |
| 其余翻页、停顿余量 | 0:30 |
| **合计** | **9:00** |

85 秒中已给逐页停顿留位置，不把“5 页 × 详细项目介绍”塞进这个预算。真实 PI 插问不受该表保证，发生后转入讨论。八到九分钟仍是内部准备目标，不是 PI 承诺的报告时长。
