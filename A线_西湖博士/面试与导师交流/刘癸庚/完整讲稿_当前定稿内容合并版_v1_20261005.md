# S2｜我的毕业设计：三维周期电阻膜吸波结构

我的本科毕业设计做的是一个三维周期电阻膜吸波结构，主要想在 2 到 18 GHz 这个范围里，把低反射的频段尽可能做宽。

一开始导师给我的是比较宽泛的电阻膜型吸波材料方向。后来带我的师兄给我看了一些相关工作和他自己做的多层二维材料，也建议我可以考虑做三维结构。于是我最后具体做出来的是左边这个周期单元：两张电阻膜竖直放置并且相互正交，用 PET 做支撑，XY 方向周期排列，底部设成 PEC 理想电边界，电磁波从上方正入射。

右边是最后两张膜各自的图案，因为三维 CST 图里面有遮挡，所以我把它们单独放出来。

我现在重新理解这个结构的话，它本质上还是一个电磁场、表面电流、散射和耗散互相耦合的自洽问题。想让吸收效果比较好，一方面要让最后返回入射侧的能量尽可能少，另一方面又需要让阻性膜里面确实可以产生足够的耗散。

所以后面我要解决的问题就是：**这个结构里到底哪些参数可以主动去设计，它们分别会改变什么？**

### 被追问时可展开

- 当时选择三维并不是经过完整理论推导后得出的必然结论。历史上主要是师兄建议可以尝试三维结构，本人当时也觉得更有意思、愿意尝试；现在复盘时，才更清楚地理解三维结构提供了额外的空间设计自由度，例如不同高度的场分布、膜与 PEC、两张膜之间更丰富的电磁耦合等。
- 不把“更多空间自由度”直接升级为“已经验证更多共振导致宽带”；本项目未完成足以支撑该结论的模态 / 阻抗 / 等效电路分析。
- 两张正交膜是本人在复杂度与设计自由度之间做的结构选择；历史上也考虑过更复杂的三膜 / 三角形类似结构，但没有采用。

# S3｜这些参数分别在改变什么？

我后来主要采用了四类参数：周期、高度、膜面的图案，还有两张膜各自的片阻。

周期首先改变的是结构的横向尺度，也就是整个周期相对于波长到底有多大。它同时会影响周期条件、单元之间的电磁作用，以及 Floquet 通道什么时候能够成为传播通道。

高度主要改变纵向的电尺寸。因为下面有 PEC，向下传播的场会被反射回来，所以高度一变，返回到电阻膜附近的场相位也会跟着变，内部场分布和表面电流自然也会发生变化。

图案的功能就更直观一些。原来是一整张连续的电阻膜，加入镂空或者条带以后，相当于直接改变了电流能够从哪里走，哪些边缘容易积累电荷，以及局部场怎么分布。所以相对于只调周期和高度，图案能给出更多局部尺度上的设计自由度。

片阻又是另一类参数。它更直接改变局部切向电场和表面电流之间的关系。片阻变化以后，表面电流会变，而电流本身既参与欧姆耗散，又会产生散射场，所以它也会同时影响耗散和反射。

所以这些参数并不是几个互相独立的变量，它们只是以不同的切入点改变这个自洽的系统。最后这些参数的变化都会反馈到内部的场和表面电流，再影响反射和耗散。

那么我实际做项目的时候，肯定不是一开始就把这四类参数全部扔进 GA 里面一起搜索。那样的话设计空间一下会变得非常大，在我当时的计算资源下很容易搜不充分。

# S4｜后来，我怎么决定下一步改什么？

所以这里我需要讲讲我的设计过程和决策思路。

首先我肯定不能一次开放所有可能的参数。一方面是我自己需要一个循序渐进的过程，在做的过程中熟悉 CST 的各种操作以及 Python；另一方面仿真工程量会迅速变得很大，而且高维空间里会有大量低价值的候选，占用很多计算时间。

所以最开始我主要只调周期和高度，同时先用少量固定的材料参数。一方面是把 CST 和 Python 的参数化仿真真正跑通，另一方面也是先找到一个大概有效的尺寸范围。这样以后再加入新的自由度，就没必要每次都重新从很大的周期和高度范围开始扫。

后来只继续调这两个参数时，性能提升越来越有限。我们的目标又不是只在某一个频率附近得到一个很深的反射谷，而是希望比较宽的一段频率都能保持较好的响应，所以我当时判断，只靠这两个全局尺度已经不太够了，于是选择加入更局部的图案自由度。电阻膜图案的引入会改变局部电流的流向、电荷的累积以及场的分布和电磁储能，这就有更多调控空间。

一开始图案分辨率还比较低，也做过一些比较简单的条带状尝试，效果比较一般。后面把图案的自由度放得更高以后，出现了一组表现比较突出的结构，就是这里看到的纺锤形镂空和中央条带组合。于是我把这个组合作为表现较好的母型，继续提高图案分辨率，在这个结构思路上做更细的搜索。所以从 6×6 到 9×9，再到 12×12，我更愿意把它理解成一个**先找到表现较好的结构家族，再继续细化局部自由度**的过程。

到 12×12 左右的时候，继续把图案做得更细，计算成本已经越来越高，性能提升也又开始变慢。下一步要么继续提高图案分辨率，要么加入一种性质不同的新自由度。考虑到我的笔记本计算能力，我最后选择把片阻加入搜索。

当时还有一个并行的工程考虑：我最早其实考虑过把样品做出来，所以片阻和膜厚用的是当时可以买到的成品电阻膜参数；但实际尝试装配时，我发现这种细长、竖直交叉的电阻膜很难把位置和形状误差控制得很好。后期我逐渐不再把设计严格限制在最初那些商品膜参数上，而是把两个方向的片阻也开放成连续变量。现有记录不能把“装配困难”和“开放片阻”写成已经查明的单一直接因果，因此这里只作为两个当时都存在的考虑来讲。

物理上，片阻作为新自由度也是合理的。图案首先改变的是空间边界和电流路径，而片阻首先改变的是局部切向电场与表面电流之间的关系，也就是局部的 E_t–K 关系。它们进入整个自洽系统的路径不同，但最后都会改变内部总场、表面电流、散射和耗散。

所以总的来说，就是通过工程上和物理上的考量，在每一轮参数跑出来以后再做一轮决策：是继续基于现有较优参数搜索当前空间，还是判断当前优化已经进入瓶颈，需要开放新的自由度。

如果现在让我总结整个过程，我觉得我真正持续在做的并不是开发 GA 本身。**GA 是在我给它的空间里面找候选，而我需要不断判断的是：这一轮还有没有必要继续搜；如果已经出现瓶颈，下一步应该开放什么新的自由度；以及这一轮找到的哪些结构值得保留到下一阶段。**

换句话说，我一直在逐步决定：**GA 下一步到底允许探索什么样的结构。**

# S5｜最终结果：做到了什么，还缺什么？

经过前面几轮设计空间的扩展以后，最后保存下来的一组结果，在 2 到 18 GHz 的扫描范围里，指定同模反射不高于负 10 dB 的最长连续采样区间是 4.80 到 18.00 GHz，对应的端点跨度是 13.20 GHz。

这个结果当时我是比较满意的，因为从最开始只调周期和高度，到后来加入图案、提高图案分辨率，再加入双片阻，目标响应确实一步一步被往前推了。

但是现在重新看这个结果，我会比当时谨慎很多。

首先，18 GHz 本身就是当时扫描的上限，所以这里只能说低反射区间一直延伸到了我的观察窗口终点，不能说 18 GHz 就是结构真正的高频截止。

更重要的是，当时保存和优化主要关注的是指定的同模反射。后来我重新核对原始工程才发现，CST 实际上在 Zmax 独立求解了 TE(0,0) 和 TM(0,0) 两个正入射 Floquet 基模，结果树里也登记了两个同模和两个交叉模式的反射通道；但是当时 Python 和 GA 始终只读取 `SZmax(1),Zmax(1)`，也就是 mode 1 到 mode 1 这一条同模反射。现有证据又不能把 mode 1 唯一翻译成 x 或 y 线偏振。

所以目前最严谨的说法还是：**4.80 到 18.00 GHz 是 mode 1 同模反射不高于负 10 dB 的连续采样区间，13.20 GHz 是端点跨度，而不是已经完全验证的总吸收带宽。**

这也是我现在重新做这个项目复盘以后感受很明显的一点。当时我的思路更多还是工程性能驱动的：GA 还能不能继续把曲线往下压，低反射带宽还能不能继续变宽。曲线出来以后，会比较自然地觉得这个结果已经做得不错了。但现在回头看，我当时对这个项目的理解更多停留在性能优化层面，并没有把结果为什么成立、到底有多可靠这些问题真正吃透。

所以如果现在让我继续做，我第一件事不会是马上把 GA 做得更大或者继续加入新的自由度。

我会首先把所有开放传播通道的功率算清楚，确认能量到底去了哪里；然后通过改变网格、扫频设置等做独立的数值稳定性和收敛性验证；等这些结果真正可靠以后，再去看局部场、表面电流，以及必要的阻抗或者模态分析，探讨为什么这个结构会出现这样的宽带响应。

所以现在回头看，我觉得这个项目最重要的收获其实不只是最后这条曲线，而是我在复盘的时候真正意识到：**做研究不能只停在“把结果做出来”。我还需要理解自己到底在做什么，验证这个结果是不是可靠，最后再尽可能解释清楚它为什么会这样。我想这是这个项目后来给我最重要的一项经验。**

### Defense 备查：偏振 / S 参数边界

- 最终 `Zmax` mode 1 = `TE(0,0)`、mode 2 = `TM(0,0)`，两个模式被独立求解。
- CST 结果树登记了四个 Zmax 反射通道：两个 co-pol、两个 cross-pol。
- Python / GA 只读取 `SZmax(1),Zmax(1)`，没有读取 mode 2、cross-pol 或总反射功率。
- 13.20 GHz 对应 mode 1 → mode 1 co-pol；现有证据不能把 mode 1 唯一映射成 x/y 偏振。
- 独立 `.sig` 数值文件缺失，现有保存数据不能报告 cross-pol 的具体 dB 大小。
- 本人回忆当时师兄曾说“看 S11 就行，其他不用管”。这个回忆只能解释本人当时为何没有继续查其他通道，不能替师兄推断理由。

# S6｜二维尘埃等离子体晶格波合作研究

除了毕业设计，我还参与过一项二维尘埃等离子体晶格波的合作研究。我的任务主要是做偏振相关的数据处理和粒子轨迹可视化。

这里的偏振指的是颗粒在平面内怎么振动。我用 MATLAB 把粒子的 x、y 两个运动分量组合成二维轨迹，再去比较不同空间位置的差别。最后整理出了这里这组 41 个位置的轨迹图，也进入了论文的 Fig.12。

比较直观的现象是，一些对称位置上的轨迹接近直线，而其他位置会出现明显的椭圆。论文把它解释成不同方向振动分量之间存在相位延迟。

这项工作对我来说比较重要的一点，是让我第一次比较完整地接触了团队科研里面从模拟数据到物理图像，再到论文图件这一段工作。

### 被追问时的贡献边界

已确认本人参与 MATLAB 偏振相关数据处理、二维轨迹可视化与图组整理。41 图进入本人名下工作簿并与论文 Fig.12 对应，不证明本人独立完成全部模拟。核心模拟由谁运行、具体改到核心代码哪层、是否设计求解算法、是否撰写正文 / 图注、是否首先提出机制解释仍未核实。线状 / 椭圆状是图形观察；相位延迟是论文归因，不主张本人独立提取和验证了相位差。

# S12｜为什么我想继续接受科研训练｜Why PhD

我想继续深造，其实和我本科这几年做的一些事情是连在一起的。

我觉得首先我其实对做研究，或者说对问题和未知是有相当的好奇心和兴趣驱动的，我觉得自己也喜欢做这种探索性的工作。大二的时候，因为对老师提出的波纹管能吹出稳定的乐音的问题感兴趣，决定参加并且作为负责人做了这个小项目，这也是我第一次尝试自己设计实验、用代码处理数据和分析结论；后来 AI 工具开始快速发展以后，我又做过物理学习 Agent、学习系统这些东西。它们不一定都是很成熟的项目，尤其早期的 Agent 现在回头看其实有不少过度设计和重复造轮子的工作，但这些经历让我越来越确信，我很喜欢那种从一个模糊的问题出发，逐渐把它变成一个可以研究、可以实现的项目的过程。

另一方面是基于我对 AI 时代的思考，从 AI 进入我的学习和生活以来，我一直在思考的问题就是“未来到底需要人的什么能力”，这一点在我的公众号和个人艺术网页里都有一些探讨。至少目前来看我觉得，过去我们更希望熟练掌握标准化重复性的专业技能，尤其是脑力劳动，而 AI 正在逐渐掌握这样的能力。所以我希望趁自己还有这种“无知的热情”的时候，尽可能有一段完整的时间来探索自己的能力边界和培养属于自己的独特价值，比方说我能不能在领域里提出真正有价值的问题；当我面对一个复杂问题或者项目的时候，我能不能很好地拆解它的工作流并且判断哪些内容可以交给人工智能处理而哪些环节必须要我来主导，也就是之前很热门的“human in the loop”；当我面对一个具体问题的时候我能不能有效地组织和管理人工智能解决问题，以及我是否具备分辨人工智能工作结果质量的专业判断力，这是我本科期间就在思考、但尚未形成的能力，也是我希望继续深造的一个非常重要的原因。

像我的毕业设计对我来说就是很具体的例子。当时做毕设的时候我可以借助 Python、CST、GA 和 AI 把自动优化流程推进下去，但现在重新回头看，我会发现自己当时对能量通道、输入阻抗、宽带机理以及结果可信度这些内容的理解是不够的。很多当时看起来很重要的实现工作现在 AI 已经可以做得越来越好了，而真正暴露出来的短板恰恰是我的专业判断能力和理论深度。

所以我现在想继续接受科研训练，并不是因为我觉得博士能让我学到一些“AI 永远不会的技能”，我觉得至少目前以我的认知能力而言，我还不能准确地说什么能力是 AI 永远无法替代的，但至少从我自己所做过的工作来说，我希望把自己的能力重心从执行和掌握一些固定的工作流，逐渐转移到能够提出值得研究的问题、把问题定义清楚、判断结果、识别错误、决定下一步方向，以及有效地组织 AI 和其他工具完成研究这些事情上。我想这种能力光靠本科这样零散地做几个项目肯定是做不到的，它需要在一个领域里长期深入，真正理解自己手头的工作，同时不断接受导师和同行的挑战，最后能够真正对自己的研究判断和结论负责，并且拥有属于自己的研究品味的过程。
