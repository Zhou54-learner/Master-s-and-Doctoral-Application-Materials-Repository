## 新的叙事

S9 围绕“本人长期要做什么、其中哪些环节适合交给 AI”展开。完整截图和视口位置沿用 v2；A/B 是同一套个人工作系统的两个视角。

| 帧 | 页面问题 | 口述承担的内容 |
|---|---|---|
| A：长期状态／空间进度 | 我长期要完成什么？我现在走到哪里？ | 重要但重复、组织成本高的任务；时间进度与知识空间进度；地图标记不等于自动掌握判断 |
| B：当前执行／下一步行动 | 我下一步具体做什么？ | 材料、任务、通过条件；计划、讲解、出题、校对、错题和复习、真题分析、薄弱点训练；本人保留理解、正确性和取舍 |

## 复现

在本目录依次运行：

1. `python 制作源/build_slides.py --only both`：只生成两个 v3 目录中的 S8 和 S9；可用 `s8` 或 `s9` 单独生成。
2. `python 制作源/render_pair.py`：仅只读打开新候选并导出；不保存原 PPTX。
3. `python 制作源/review_sequence.py`：读取 S7 v2 A、S10 v2 A 现有 PNG 与新候选 PNG，组合审阅图。
4. `python 制作源/validate_delivery.py`：检查交付、截图沿用、文档链接、notes和连续图来源。
5. `python 制作源/preserve.py check`：对接手基线核对，不能重建或覆盖原基线。

依赖 python-pptx 1.0.2、Pillow 12.3.0、pywin32、Microsoft PowerPoint 16.0、pdfinfo、pdftoppm；已用现有环境完成，无新安装。新目录打包原截图，重建不运行历史应用；方法论原件仅按路径与哈希登记。源文件、图像及渲染元数据都保存在候选目录中。
