# 本科毕设 S2–S5｜v1 → v2 修改说明

2026-10-05｜INTERNAL

这次改版不重新核验科研事实，也不改变 S2–S5 的四页叙事。目标是让页面更像本人在和导师介绍自己做过的项目：图先说话，文字只留下现场必须看到的关系。

## 1. 哪些表达被判为 AI / 咨询式语言

| v1 表达 | v2 处理 | 原因 |
|---|---|---|
| “面向宽带低反射，构建三维周期电阻膜单元” | “我的毕业设计：三维周期电阻膜吸波结构” | 先说这是我做的什么，不先写成项目摘要 |
| “四类自由度，在不同层级塑造同一电磁响应” | “这些参数分别在改变什么？” | 改成导师会自然追问的问题 |
| “共同落点：同一个 Maxwell 自洽系统” | 删除大口号，放入备注现场解释 | 概念继续保留，正文不替本人把理论讲完 |
| “整体散射 / 匹配状态 + 阻性耗散” | “反射要少，能量也要真正耗散在电阻膜中” | 更接近本人可以直接说出的因果 |
| “我逐步扩展的是物理设计空间” | “后来，我怎么决定下一步改什么？” | 把分类总结改成研究决策 |
| “优先闭合三个问题” | “如果现在继续，我会先做” | 从咨询式任务标签改成第一人称行动 |
| “材料阻性响应” | “片阻：同样的局部电场，电流有多大？” | 先讲具体关系，再保留符号 |

S3 的“单元之间的相互作用”、Floquet 通道条件、局部 `E_t–K` 关系等术语没有删除，因为它们是准确的物理内容；只是把它们放进较短、可以现场解释的句子里。v2 没有把一般解释升级为本项目已经证明的机理。

## 2. 哪些卡片和标签被删除或降级

- 删除 S2 顶部大目标横条和底部摘要框；目标改为左上短句，结构图得到更大面积。
- 删除 S3 四张等宽参数卡片、统一箭头链和“Maxwell 自洽系统”大汇总框；改为 C07 结构示意、h 标注、C18 图案和三段自然提问。
- 删除 S4 三列阶段框、`01/02/03` 分类编号、两个“收益递减 / 成本上升”总结条；这些关系改由左右文字、真实图案和箭头表达。
- S4 工具链降为页脚一句“工具帮我试这些选择”，保留 GA、Python、CST 的准确角色但不让工具成为主语。
- S5 删除“现在继续：优先闭合三个问题”框和底部 slogan；三件后续工作直接写成动词短句。
- 页脚保留来源和边界，因为它们帮助追问时定位证据，不作为主讲内容朗读。

## 3. 每页现在的唯一主视觉

- **S2：** C01 原始 CST 三维结构。C18 只负责补足被遮挡的 X/Y 图案。
- **S3：** C07 结构示意和 h 的空间关系；右侧图案让“电流从哪里走”有可指的对象。
- **S4：** C12 → C15 → C16 的真实图案演化。右侧 C18 只说明片阻自由度进入后仍沿用图案，不和中间演化争主次。
- **S5：** C22 原始 201 点曲线。X/Y 图案与 CST 结构只是结果旁边的身份回忆。

## 4. S4 如何从阶段分类改成研究决策

v1 用“全局几何 / 局部拓扑 / 材料阻性响应”三个并列栏解释路线，事实正确但容易像事后分类。v2 改成一条本人可以讲述的判断链：

1. 起初只调周期、高度和少量固定材料，先学会 CST/Python、跑通参数化仿真并在有限算力下找范围。
2. 只调尺寸后提升变慢，于是开始加图案；出现较好的 X 中央条带和 Y 阶梯镂空母型后，保留它继续从 6×6 做到 9×9、12×12。
3. 图案进一步细化的成本上升、提升变慢，于是面临“继续加细，还是试试片阻”的选择，后续开放 `R_{s,x}, R_{s,y}`。

每个节点都能单独停下来回答“当时看到了什么”“为什么保留”“哪些因果仍不知道”。装配困难和商品膜约束作为本人确实考虑过的现实背景放在口述中，未写成片阻放宽的已证直接原因。

## 5. 精简是否改变事实含义

没有改变结果数字、结构边界、设计演化链或 ownership。唯一的表达压缩是：

- S2 把“整体散射 / 匹配状态 + 阻性耗散”写成口语化目标，仍然只表达一般物理方向；没有变成总吸收结论。
- S3 将四类自由度分散到结构示意和图案旁的短句，省略了 v1 的统一箭头，但备注保留 `E/H/K`、散射与耗散关系。
- S4 将“收益递减”“成本上升”写成本人回顾中的“提升变慢”“更费算力”，没有添加定量比较或精确历史时间。
- S5 将“闭合”改成“算清楚”，没有降低后续验证要求；全通道功率和数值可靠性仍是先做的工作。

## 6. 继续保留的边界

C01 捕获参数 UNKNOWN；C07 是后期复盘结构示意；6×6→9×9 严格映射、片阻放宽建议者/时刻以及装配与片阻的直接因果 UNKNOWN；S3 不声称具体模态、多共振、RLC 或输入阻抗已验证；S5 的 4.80–18.00 GHz 是指定同模反射 ≤ −10 dB 的连续采样区间，13.20 GHz 是端点跨度，不是总吸收带宽；全通道功率、独立收敛、宽带机制、制造/实验仍待验证；没有扩大本人 ownership，没有新增仿真或修改原科研素材。
