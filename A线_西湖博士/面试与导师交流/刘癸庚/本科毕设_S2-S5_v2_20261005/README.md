## v1 → v2 的实质改动

完整记录见 [v1→v2修改说明](v1→v2修改说明.md)。核心变化是：

1. S2 标题改为“我的毕业设计：三维周期电阻膜吸波结构”，并把 C01 放大为唯一主角；“整体散射 / 匹配状态 + 阻性耗散”改成“反射要少，能量也要真正耗散在电阻膜中”。
2. S3 删除四张等宽卡片和最大化的“Maxwell 自洽系统”口号，改为结构示意 + 图案 + 三个可自然追问的问题；保留四类自由度及其准确边界。
3. S4 删除三列分类框和两个阶段总结条，改为左侧“先跑通”、中部“这个母型不错”、右侧“继续细化还是试试片阻”的研究决策路径；工具链降为页脚支撑。
4. S5 标题改为“最终结果：做到了什么，还缺什么？”，把“现在继续：优先闭合三个问题”改为“如果现在继续，我会先做”，三个动作改成普通说法。
5. 逐页备注全部重写。允许自然出现“我当时发现”“后来我觉得”“这时候面临的选择是”，每段可被导师打断；不再把四页硬压成精确 4 分 05 秒。

## 事实边界继续保留

- C01 的捕获工程、时刻和准确参数仍 UNKNOWN；它是结构族的历史 CST 视图，不单独认证 13.20 GHz 那次求解。
- C07 是 2026-09 申请准备阶段依据保存掩码绘制的结构示意，不是历史 CST 导出或样件；h 辅助线只表示膜高，不跨空气区。
- S3 的物理连接是当前一般电磁学理解；没有写成已完成的输入阻抗反演、RLC 拟合、具体模态或多共振证明。
- S4 保留 C12 → C15 → C16 → C17/C18 的可追溯链；6×6→9×9 严格逐像素映射、片阻放宽的具体建议者/时刻及其与装配考虑的直接因果仍 UNKNOWN。
- S5 保留 2–18 GHz、201 点、0.08 GHz 间隔、4.80 首个连续通过点、18.00 扫描上限和 13.20 端点跨度；不写成总吸收带宽。全通道功率、独立收敛、宽带机制、制造和实验闭环仍待验证。
- v1 文件夹及其中全部文件按哈希保全，v2 独立存放；没有覆盖或修改原科研素材，没有运行 CST/GA。
