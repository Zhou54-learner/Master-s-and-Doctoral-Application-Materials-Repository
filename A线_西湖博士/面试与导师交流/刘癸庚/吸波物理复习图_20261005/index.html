01 / 自洽场

场驱动材料，材料又改变场

不是入射波依次经过“电阻膜 → PET → PEC”。两张竖直正交膜、支撑介质、背板和周期阵列一起参与同一个边值问题。

给定入射频率、波矢、偏振和入射功率；入射 E 与 H 满足外部介质中的平面波关系。
局部总场入射场与整个周期结构产生的散射场相加；材料实际感受到它。
电流 / 极化膜上 K，PEC 上 K 与面电荷，PET 内 P；响应由总场与本构共同约束。
响应产生场全部感应源形成新的场，包含相邻单元的贡献，再回到“局部总场”。
闭环关系：E总 = E入射 + E散射[K膜, KPEC, P, 电荷；所有周期单元]。H 也满足同样的叠加关系。入射振幅固定，不代表膜面 Eₜ 固定。

电阻膜：传导与电荷积累

Eₜ = Rₛ K
∇ₛ · K + iωρₛ = 0采用 eiωt；第二式适用于无额外法向注入的薄片。K：A/m；ρₛ：C/m²；∇ₛ 是面内散度。

面内电流并非处处等强。电流汇聚、终止或在边缘受限时，局部感应电荷与切向 / 法向电场也随之变化。这些电荷和电流都参与散射。

PET：支撑，同时发生极化

D = ε₀E + P
P = ε₀χe(ω) E第二式是局部线性各向同性模型；一般介质可用张量本构。P 是极化强度，不是功率。

极化形成束缚电荷和极化电流 iωP，改变局部场、相位和储能。只有模型包含相应损耗时才产生介质耗散；“能极化”不等于“必定发热”。

本项目 PET 参数要从实际材料定义核对；此图不臆定其耗散占比。

PEC：有表面电流，没有欧姆耗散

Eₜ = 0，　KPEC = n̂ × H外n̂ 从理想导体指向外部；此式采用内部场为零的理想 PEC 模型。

边界要求表面切向总电场抵消为零，所需面电荷 / 面电流产生反射场。因此“没有损耗”不等于“没有响应”。

相邻单元：远场衍射与近场耦合

周期条件关联邻胞同一位置的复场。正入射时等价单元的激励同相；它们的散射场仍会相互影响。

传播级次关闭不代表近场耦合消失：倏逝空间谐波仍可改变膜边缘场、电流和整体响应。

CST 频域解究竟满足什么？

∇ × E = −iωB，　∇ × H = Jf + iωD
∇ · D = ρf，　∇ · B = 0

给定几何、材料本构、入射、周期与 PEC 等边界，求每个频率的复场。膜面满足切向 E 与 K 的关系，磁场切向跳跃与 K 对应；介质界面满足相应电磁连续条件，端口满足入射 / 出射条件。

这些方程使用宏观自由电荷 / 电流记账，PET 极化已包含在 D 中，不重复列为 Jf。这是稳态复振幅问题，不是逐帧播放电磁波的进入过程。

本项目模型有据可查：两块正交竖直 PET 支撑片、膜面图案、周期单元、正入射配置；最终 Zmin electric 表示理想 PEC 背板。h≈10.0731 mm，PET 厚 0.188 mm。示意关系不代替真实 mask 几何。
02 / 能量账

入射功率最终只能去到可核算的出口

场建立时可以储能；单频稳态下，一个周期内储能没有净积累。功率账必须包含所有出射传播通道和材料耗散。

P入 − P反 − P透 = dU/dt + P耗散
⟨dU/dt⟩ = 0 ⇒ ⟨P入⟩ = ⟨P反⟩ + ⟨P透⟩ + ⟨P耗散⟩第一行是完整系统的能量记账：U 含可恢复储能；色散材料不能随意只用 ½εE² 表示全部储能。本文功率比较以下均取时间平均。
反射 R总同模 + 正交偏振 + 所有开放空间级次；在同一入射功率下归一化。
透射 T总若背面有传播出口应计入；本项目理想 PEC 底边界封住该出口。
吸收 A膜面损耗积分 + 其他有损材料的体损耗积分，除以入射功率。

无限周期模型中，成对侧边界的净平均功率相抵。有限阵列、边缘漏波或额外端口需要重新列账。

从 Poynting 能流到材料损耗

⟨S⃗⟩ = ½ Re(E × H*)，　P穿面 = ∫ ⟨S⃗⟩ · n̂ dA
P耗散 = Σ膜 ∫ ⟨qₛ⟩ dA + Σ有损体材料 ∫ ⟨qᵥ⟩ dVS⃗ 是能流密度（W/m²），不同于散射系数 Sᵢⱼ；qᵥ 为体耗散密度（W/m³）。材料损耗只按实际模型计入，极化本身不自动等同耗散。

一边从包围结构的边界积分净功率，另一边从膜 / 材料积分损耗；二者一致才构成独立的能量闭合检查。

PEC 为什么封住透射？

模型在底部直接施加理想导体边界，场不进入背后的传播区域；法向 Poynting 功率穿过该面为零。因此这个模型的 T=0。

真实足够厚的良导体背板常可使透射很小，但仍取决于材料、厚度、频率和缝隙；此处不把理想边界等同实际样件验证。

PEC 为什么可以有电流却不发热？

qPEC = ½ Re(Eₜ · K*PEC) = 0

理想 PEC 的 Eₜ=0，即使 K 非零也没有该表面平均电功耗散。它通过散射改变其他位置的场与损耗。

完全无损、PEC 封底且无其他出口的稳态结构，最终必须把全部入射功率反射回去。

03 / 输入阻抗

输入阻抗是整个结构从入射侧呈现的响应

它不是一块膜的局部片阻，也不是任意位置 E/H 的比值。先指定端口 / 参考面和模式，再讨论等效输入阻抗。

Zin = Rin + iXin

实部 Rin：输入端口电压与电流的同相分量，对应平均实功率被结构接受。若为 PEC 背衬且仅有一个外部传播通道，接受的功率最终耗散；若有其他通道，也可转成其他模式出射。

虚部 Xin：端口响应的正交分量，描述反应性 / 可恢复储能效应。eiωt 约定下，正电抗通常称感性，负电抗通常称容性；复杂色散结构不能简单按符号定位某片膜的储能。

为什么是约 377 + i0 Ω？

Z₀ = √(μ₀ / ε₀) ≈ 376.73 Ω
Γ = (Zin − Z₀) / (Zin + Z₀)
Zin = Z₀ (1 + Γ) / (1 − Γ)

空气正入射、选定同一参考面的标量模式描述。Γ 必须包含复相位；斜入射时 TE/TM 波阻抗不同，多模式或偏振转换应使用阻抗 / 散射矩阵。

Xin 接近 0反应性失配减小，有助于匹配；但它不是充分条件。
Rin 接近 Z₀实部也接近外部波阻抗，两者共同降低 |Γ|。
正确的端口描述仅同模 Γ≈0 不能排除能量被转换成正交偏振。

从后向散射抵消看匹配

感应电荷 / 电流膜、PET 和 PEC 的响应由局部总场共同决定。
各响应产生后向场每一贡献有振幅、相位和偏振；需要在同一观察模式中相干相加。
总反射场变小合适相位与振幅可使后向贡献抵消，对应相应反射模式的匹配。

反射波本质上来自全部感应源产生的总后向散射。也可把 PEC 背板先选为“背景”，再让膜 / PET 的散射补偿背景反射；两种分解给出同一总场，不能把背板反射重复计数。

抵消的是场振幅，不是直接把两个功率相减。没有损耗且无别的出口时，稳态能量守恒禁止所有反射功率都消失。

本项目边界：没有用复 S 参数、参考面去嵌与多模式核验建立 Zin(ω)。保存的幅度曲线没有相位，不能唯一恢复复输入阻抗；也不能说“片阻约等于 377 Ω 就匹配”。
04 / 局部本构与耗散

片阻改变的，是场—电流—散射的整套平衡

对一个纯电阻、各向同性的 Ohmic Sheet，局部总切向电场和表面电流直接相关。真实的 Eₜ 和 K 都由整个结构的自洽解决定。

Eₜ = Rₛ K，　K = Eₜ / Rₛ
⟨qₛ⟩ = ½ Re(Eₜ · K*) = ½Rₛ|K|² = |Eₜ|² / (2Rₛ)
⟨P膜⟩ = ∫膜面 ⟨qₛ⟩ dA使用峰值复振幅而非 RMS，故有 ½。Eₜ：V/m；K：A/m；qₛ：W/m²；积分后 P膜：W。J 是体电流密度（A/m²），不可和 K 混用。

这三种耗散表达式在同一个解中等价。用 Rₛ|K|² 讨论时不能偷偷固定 K，用 |Eₜ|²/Rₛ 讨论时也不能偷偷固定 Eₜ。

改变 Rₛ改写膜面局部本构关系。
K 与电荷分布改变原总场下的响应不再满足新条件。
散射场重新建立邻胞、PEC 返回场与 PET 极化也受影响。
新总场与新耗散Zin、反射、损耗同时改变。

为什么不是越小越好？

低片阻可能支持更强的屏蔽 / 反射，也会改变局部 Eₜ。理想零电阻表面不是有耗散的膜，不能用“电流大”单独推断“吸收大”。

为什么不是越大越好？

高片阻趋向弱导电，电流与耦合可能减小。局部材料更难导电不等于结构更能从入射波提取能量。

两个方向片阻是什么？

本项目两张正交膜分别赋值 Rₛ,x 与 Rₛ,y。它们控制各自膜面电流关系，最终保存值分别为 140.79、35.461 Ω/□。

这不是“同一张膜沿 X/Y 两方向必有各向异性”的证据，也不意味着每个入射偏振只激发一张膜；实际响应仍耦合。局部各向同性片阻不会因为电流斜着走就变成另一个 Rₛ。

匹配与欧姆耗散是同一解的两个观察角度：前者看入射侧的整体场 / 模式关系，后者看内部 Eₜ·K* 的实部积分。改变片阻会同时改变两者，不能将它们设想成先后独立优化的两个开关。
已核事实：最终使用 Ohmic Sheet；连续双片阻在后期才开放。数值可赋值不等于相应实物材料已可采购或在整个微波频段严格服从恒定实数片阻。
自测：片阻翻倍，耗散是否翻倍？

固定电流时是；固定电场时反而减半。但同一外部入射下改变片阻，局部电场和电流都要重新求解，因此一般不能给出单调答案。

05 / 电尺寸与高度

毫米是几何长度，kh 才告诉你相位走了多少

同一个结构面对不同频率，会占据不同的波长比例。高度改变的不只是“材料更多”，还包括返回场相位、场的空间分布和耦合条件。

几何尺寸与电尺寸

λ₀ = c / f，　k₀ = 2π / λ₀
h / λ₀ = hf / c，　k₀h = 2πhf / c

h 是长度；h/λ 与 kh 无量纲。同一毫米高度，频率越高，沿该长度积累的相位通常越多。介质内部应考虑其传播常数，不能全用空气波长替代。

高度怎样回到局部电流？

传播到 PEC 再返回会积累往返相位；PEC 对切向电场的反射再带来相位反转。返回场与其他场在膜附近叠加，改变 Eₜ，进而改变 K 与散射。

本结构是分布在整个高度上的竖直膜，不是全部位于同一高度的平面电阻片；不能用单一路径概括完整场分布。

h 或 f 改变改变纵向电尺寸 kh。
传播与返回相位变化同时影响空间干涉及耦合。
膜附近总场改变有的位置增强，有的位置减弱，需看复场。
K、Zin 与反射变动耗散也随局部场一起改变。

06 / 图案自由度

图案先改电流可走的地方，再改整套场响应

图案不是直接贴一个“共振标签”。它改变导电区域、边界和相互作用，才进一步改变输入阻抗和反射谱。

导电区域 / 边界改变保留、切断、缩窄或延长某些膜面区域。
电流路径改变可走路径、有效长度、局部 K 与分流方式变化。
电荷与场重新分布边缘、间隙可积累电荷并增强局部 E；电流产生 H。
分布式响应改变电阻耗散、电场储能与磁场储能共同调整。
电阻性

哪里流、流多强

Rₛ给出局部耗散关系；几何决定电流分布与面积积分。窄颈可能提高局部电流密度，但不是必然提高总吸收。

电容性

边缘和间隙的电荷

相邻边缘上的电荷与强 E 支持局部电场储能。响应还取决于间距、PET 与邻近导体 / 邻胞。

电感性

路径周围的磁场

流动电流建立磁场及相关储能。路径长度、回流 / 位移电流闭合方式与相互耦合共同影响响应。

图案 → {K 的分布、边缘电荷、E/H 储能、耗散}
→ 局部总场与有效反应性 → Zin(ω)、散射与反射谱

这是把复杂场响应对应到“阻性、感性、容性”的一般理解图像。具体等效电路还需要明确拓扑、频率适用范围、参数提取与独立对照；不能从外形直接读出唯一 RLC 电路。

12×12 是设计像素分辨率，决定允许出现哪些图案细节；它不等同 CST 求解网格分辨率，更细 mask 不自动意味着数值更准确。

本项目没有完成：具体等效 RLC 拟合、已验证的模态归属或两张膜的独立频段分工。“纺锤形镂空”“条带”“低频骨架”等可描述形态 / 设计意图，不能直接作为已证实机理名称。
自测：为什么局部断开的金属 / 电阻片仍可能参与响应？

时变电场可使局部电荷振荡，片内仍有电流，片间有电容耦合与位移电流。没有一条贯穿全层的直流导电路径，不等于没有电磁响应；实际强弱仍需求解。

07 / 共振与储能

共振可以帮助匹配，却不能替代耗散

共振是结构的某种电磁响应在特定频率附近特别显著的现象。用 RLC 或单模图像理解很有帮助，但它们仍是有适用条件的近似。

电场储能如边缘电荷、间隙与介质附近的能量。
与磁场储能交换电流和磁场建立，又把能量返还到电场 / 电荷。
适当频率驱动可持续补偿辐射和材料损耗，形成显著响应。
端口反应性可能抵消有机会使 Xin 接近 0，但实部与耦合仍需合适。

为什么共振附近可能有强场 / 强电流？

驱动与该响应耦合时，能量在结构中反复交换和暂存；每周期输入补偿损耗与辐射，局部幅度可以提高。耦合很弱或阻尼很大时，增强未必显著。

如果场主要增强在无损区域，或耗散与外部耦合不合适，未必形成强吸收。

“电抗抵消”的简单图像

X(ω) = ωL − 1/(ωC)
ω₀ = 1/√(LC)

这是串联 RLC 类比。ω₀附近 L、C 反应性相抵消；复杂开口、耦合、有损结构的共振频率、反射谷和 Xin=0 位置不必严格重合。

为什么高 Q 通常窄？

Q ≈ ω₀ × 储能 / 总损失功率，　Δω / ω₀ ≈ 1/Q适用于可分辨、近似孤立的窄共振。总损失含材料耗散与向外辐射；“损失”不全是吸收。
Q 高每周期泄出 / 耗掉的比例较小，储能寿命较长。
频率选择性强驱动偏离共振后，响应通常很快减弱。
单峰覆盖有限一个很深、很尖的反射谷不能自动覆盖宽频带。
强吸收需要：可把能量耦合进入相应响应，同时有合适的材料耗散。在单模单端口近似中，可用“外部辐射耦合与内部损耗平衡”理解临界耦合；损耗加得过强也可能破坏匹配。
不能据此给本项目定案：现有保存结果没有完成模态、复阻抗或等效电路分析；不得把最终宽带指定为某个已证实的磁共振、电偶极共振或多模叠加机制。监视器上的热点不是单独的模态证明。
08 / 宽带设计

宽带要求一段频率内都维持合适响应

一个孤立尖锐共振通常只能照顾窄频段。增加设计自由度，可以塑造更丰富的频率响应；它提供可能性，而不是自动证明哪个宽带机制已经发生。

相邻响应重叠

不同电流路径、耦合状态或共振响应可以在不同频率起作用；若相邻响应之间没有明显失配空档，可能拓宽低反射区。

响应之间也可能破坏性干涉，增加一个模式不保证改善带宽。

不同电尺寸与多尺度

不同长度、间隙或高度比例给出不同的相位与储能特征，让频谱形状有更多可调余地。

这里是一般设计思路，不证明本结构的某个几何片段单独主导某个频率。

阻性展宽

适量损耗可降低某些共振的 Q，使响应不那么尖锐；但仍要兼顾幅度与耦合。过度阻尼可能把强响应压低并造成失配。

持续靠近匹配区域

标量描述成立时，宽带低反射可看成 Zin(ω) 在宽频段内持续靠近低 |Γ| 区域。多通道时要同时压低相关反射矩阵列的总功率。

本项目不能说：已经解析最终宽带形成的完整模态分工；已经证明“多尺度 / 阻性展宽”中的某一项是唯一原因；或更细图案、更大片阻总是更好。被动结构还受厚度、损耗和色散等物理约束，不能任意宽带完美匹配。
09 / 周期与传播通道

先问通道能否传播，再问它带走多少功率

Floquet 空间级次和偏振是两个不同维度。非零空间级次未开放，仍然可能存在零阶正交偏振反射。

正入射、空气、正方晶格的简单估算

k∥,mn = (2πm/p, 2πn/p)
kz,mn² = k₀² − |k∥,mn|²
首个非零空间级次：(±1,0) 或 (0,±1)，　fc = c/p

倏逝级次仍然重要
