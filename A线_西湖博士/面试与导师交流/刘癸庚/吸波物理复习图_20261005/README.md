## 阅读方式

先看总览中的四类设计入口和自洽反馈圈，再从周期、高度、图案、片阻或反射现象进入。每节附相关节点跳转，左栏可按全文关键词检索；窄屏以主题导航与纵向关系卡阅读。主页面按主题自然纵向滚动，不压缩成一屏密集文字；独立总链图单独做桌面首屏容纳检查。

蓝色标记一般电磁图像，绿色标记项目记录支持的结论，琥珀标记未验证解释或有限条件的类比。三个交互例子仅演示功率分账、标量输入阻抗与空气中往返相位；均不冒充CST扫描或本项目参数敏感性验证。

“打印全部章节”会展示完整章节与自测答案。复数公式采用e^(iωt)和峰值复振幅，平均功率因子为1/2。输入阻抗公式明确模式、参考面和多通道限制；高度类比不把本结构认定为Salisbury screen。

## 事实与来源

项目依据为公共R1、U02、U03与2026-09-26数值核验；教学依据为Block 1/2及实际复述记录；研究定位按同级[Chat最新物理主线](../本科毕设_研究定位与物理主线_20261004.md)组织。完整可点击来源在主页面第13节，仍引用公共事实库，不建立新的事实权威源。

本轮读取本地尚未提交的《13_实际工作梳理与研究叙事底稿》作交叉参照，但不把它或既有两个公共README修改混入提交；主页面所需事实均可回到已入库的R1/U02/U03和教学记录。收益递减按本人本轮指令的研究回顾表述，不改写为受控实验结论。

公开理论只核对周期端口模式、功率归一化、正交偏振及Salisbury类比，没有对外上传私人材料。COMSOL文档仅支持一般模式记账，不能代替本项目CST配置核查。

本轮未运行CST、GA、历史优化或科研绘图程序，未启动R2/R3，不新增对本人掌握程度的判定；已发送材料不改。
