## 复现

在本目录依次运行：

```powershell
python 制作源/build_s8.py
python 制作源/render_s8.py
python 制作源/review_sequence.py
```

前两步仅重建本候选及其导出；第三步只读相邻候选的既有 PNG，生成本目录内连续审阅图。三个输入原件逐字节保存于 `制作源/输入/`，制作不再依赖临时附件路径。不要把本目录脚本用作修改 v3 或 FULL_DRAFT 的入口；已验收后的实质修订应继续另存版本。

使用现有 python-pptx 1.0.2、Pillow 12.3.0、pywin32、Microsoft PowerPoint 16.0、pdfinfo / pdftoppm。当前会话未提供 `load_workspace_dependencies` 接口，复用已安装环境，没有新增安装。
