标题为“我接下来更想把物理问题做深”。采用一条左对齐的向下递进：电磁仿真/周期结构/数值优化 → 为什么会出现这样的响应？ → 模式、边界、损耗、可靠性 → Complex Waves and Fields。没有左右能力矩阵或performance→physics口号。“topology / non-Hermitian：希望系统学习”以低权重出现，西湖物理定导培养仅在页脚。

speaker notes主述完整采用本轮制作指令4.4的 **v3四段口述**，覆盖前一天版本和v1的轻量时长设定。不为了20–30秒删稿；数值、自动化和AI仍是后续要使用的工具。已知工具基础与待学习理论保持边界；不宣称高度匹配、确定课题或指导承诺。

组名、公开研究方向、从新物理到器件实现的路线，以及西湖物理学科的定导招生培养，均附本轮核验来源。定导事实只适用于来源所述Physics，个人具体招生学科和培养安排仍以学校/导师确认，不据此改变申请状态。
