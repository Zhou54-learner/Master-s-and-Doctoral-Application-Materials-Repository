最朴素的说法：设计一种放在金属背板前的周期电阻膜结构，使选定入射偏振在2–18 GHz内尽可能宽的一段频率上反射较低。Python不断提出候选，CST计算响应，GA按指标选出较好的候选。

# 3. CST模型怎样搭建

| 设置/对象 | 实际含义与本工程实现 | 不能推出什么 |
|---|---|---|
| 周期单元 | 只画一个重复单元；p是横向周期，h是竖直高度 | 不是模拟了有限样品边缘 |
| X/Y unit cell | 相邻单元的场按Bloch/Floquet相位联系；正入射横向相移为零，代表无限周期阵列 | 不是金属侧壁，也不是把四周全部设PEC |
| Zmax Floquet port | 上方均匀区域的模式展开与激励/接收截面；本工程入射沿−z，反射沿+z | 不是实体天线或同轴插口 |
| Zmin electric | 最终History把底部设理想PEC；切向电场为零，阻断向下的功率透射 | 不是恢复了实体铜板厚度、有限电导率与背板损耗 |
| PET | 两块竖直正交支撑，厚0.188 mm；pet_x沿x展开、沿y有厚度，pet_y相反 | PET不是被像素挖掉的对象 |
| 电阻图案 | 每个mask中的1保留电阻层，0去除；图案贴在PET表面 | 12×12不是CST求解网格，也不是144个周期单元 |
| X/Y膜面 | 几何方向名称；最终片阻不同、图案不同 | 不等于mode1/mode2，也不能直接一层绑定一种偏振 |
| Ohmic Sheet | 无体厚度的等效阻性面，以表面阻抗描述电场与面电流关系 | 不代表真实薄膜没有厚度，或已录入实测ITO光学常数 |
| 入射 | theta=phi=0；两个零级偏振分别求响应 | 不等于优化器使用了两个偏振，也不是相干混合照明 |
| 求解 | 频域求解器、二阶四面体；2–18 GHz | 用CST不等于独立开发有限元求解器 |
| 输出 | 保存CST工程、复数S参数、选定场监视器/功率结果；Python另存曲线、分数、参数与mask | 一条插值输出曲线不等于每点都独立求解 |

材料输入：PET的εr=3.1、μr=1、σ=0、TanD=0.01是历史脚本命令值。保存结果中介质损耗为0，**有效损耗模型是否启用、物性来源仍【待确认】**，不能说PET已经贡献某比例耗散。最终X/Y片阻为140.79/35.461 Ω/□、虚部为0，是数值输入而非实测。（A：C349–363、738–819及G/H History；审计）

膜为什么耗散：对理想纯阻性表面，切向场驱动表面电流K，时均损耗与Re(Eₜ·K*)/2有关；纯Rs模型可写Rs|K|²/2（峰值相量约定）。但K本身随结构与Rs改变，所以“片阻越大吸收越强”不成立。这是模型物理，不是已验证的每层损耗分配。

# 4. CST到底输出了什么

**Port是空间截面；mode是这个截面上使用的一种场基底。** 一个Floquet port可以有多个模式。本工程mode1=TE(0,0)，电场沿y；mode2=TM(0,0)，电场沿x。这是查端口场得到的工程特定映射，不能把所有CST项目的mode1都记成y。正入射下TE/TM名称依赖软件基底约定。（F）

为避免两物理端口的S11/S21习惯误导，这里统一写：

`r_ij = SZmax(i),Zmax(j)`：j是入射mode，i是出射mode；均在上方Zmax。

| mode1入射 | 量的性质 |
|---|---|
| r11 | y入射→y反射：同模/同偏振反射复振幅 |
| r21 | y入射→x反射：交叉偏振反射复振幅；**不是透射** |
| r11的模平方 | 该同模通道功率比，前提是功率归一化模式 |
| r21的模平方 | 交叉反射通道功率比，同样依赖归一化 |
| R1 | 所有开放反射传播通道的功率和；本设置下为上述两项之和 |
| T1 | 所有下方透射通道功率和；理想PEC模型中为0 |
| A1 | 完整能量平衡下1−R1−T1；应与损耗积分核对 |

对mode2入射相应使用r12与r22。**不同正交通道先分别取功率再求和，不能直接把两个复振幅相加后取模平方。**

一般周期系统还可能有非零衍射级；本工程空气背景、正入射、p=13.1409 mm时首个非零级截止约22.81 GHz，高于18 GHz，因此此频段远场传播只需两种零级偏振。倏逝高阶仍可能影响近场与数值精度，模式截断是否充分还需检验。（F）

**原始项目实际读取什么？** 最后生效`extract_metrics`（C4711起）调用`cst.results.ProjectFile`，只取`1D Results\S-Parameters\SZmax(1),Zmax(1)`，对`get_data()`每行的复数取模，再算`20*np.log10(mag)`。优化目标没有读r21、r12、r22或总损耗。CST保存了更多信息，不等于GA用了它们。

**后来的核验增加了什么？** 2026-10-06/08从历史工程恢复四条反射曲线与离散功率样点。交叉项很小，但不能先验设为0；mode2同模反射接近0 dB，故不能说偏振不敏感。S矩阵的功率和与保存总反射功率相符，能量残差最大约5.48×10⁻⁵（仅已恢复样点）。这是保存模型内的一致性证据，不是全频严格收敛、实测或本科当时就完成的全通道验证。（审计/native）

**RL的符号陷阱：** 本项目沿论文把`RL=20log10|r11|`称reflection loss，为负值；射频中常见return loss定义为`−20log10|Γ|`，为正值。现场最好说“同模反射dB曲线”，先给公式。−10 dB意味着|r11|≈0.316、该通道功率0.1；只有其他反射和透射都被正确计入后才能判断总A是否≥0.9。

# 5. Python–CST自动化怎样工作

下面是一条**最终12×12版本**的真实链，不与早期30 bit混用。函数位置来自C；源文件有旧定义，以下指最后生效版本。

1. **候选产生**：`initialize_population`（5241）、`make_individual`（4537）生成字典：p/h/rsx/rsy及两张12×12整数mask，还带origin标签。先限幅、舍入与修复。
2. **缓存和约束**：`evaluate_individual`（5134）用`individual_key`（4583）查重复；`prefilter_individual`（4630）检查保留像素数、孤立点与连通分量。不合格不送CST，记零分与原因；同一候选缓存复用，不算新仿真。
3. **decode**：`run_cst`（4682）先`configure_rs_for_individual`（4669）设置两片片阻，再`decode`（4619）读p/h并展开mask。最终不是二进制整串转整数。
4. **创建工程**：`run_cst_for_params`（1747）新建CST工程；设置模板、材料、PET、图案，调用History命令。p/h多由Python数值展开到几何命令；CST参数表并没有保存所有GA设计变量。
5. **最终边界与求解**：覆盖底部为electric，设置Floquet与频段，调用`run_solver`；GA快速配置不启用网格自适应。不能只看模板前部的旧Zmin开放边界。
6. **保存/读取**：保存独立临时CST；`extract_metrics`（4711）经results API读复数r11。不是手工从截图量曲线，也不是每次必须先导CSV再解析。
7. **计算fitness**：转成dB，找最长连续通过区间，加带宽、边缘、深度与裕量奖惩；返回参数、指标及工程路径。
8. **日志/最好结果**：`log_individual_trace`（5099）、`write_best_result`（5362）等保存过程与最好个体；best_s11/mask用于回查。
9. **选择与繁殖**：`select_parent`（5187）以max(score,0)为轮盘赌权重；全非正则随机。`crossover`（5201）交换局部图案，并对连续参数做均值加扰动；`mutate`（5229）做参数/拓扑修改，再修复与筛选。
10. **下一代**：`make_new_population`（5284）保留精英和历史种子，注入模板/局部候选；`optimize`（5387）固定16个体×8轮。没有证据说明达到全局最优。

工程意义：把一次能手动做的数值评价写成可批量重复的流程，才有可能搜索多变量。参考框架已有；我的工作是具体问题的建模、扩展、排错和结果整理，与AI协作完成。（U）

# 7. Fitness function是什么

fitness是“告诉搜索器喜欢哪类曲线”的人为评分，不是自然定律、吸收率或泛化性能。

## 7.1 先算什么

最终C4711–4803：读r11→RL=20log10|r11|→找`RL≤−10 dB`的连续样点段→取端点跨度最大的段，**B=f_high−f_low**。代码实际用≤，不要仅凭日志标签中的`<`改写实现。

最终201点、0.08 GHz输出间隔下，4.80到18.00的端点跨度为13.20。辅助量`B_total=通过点数×平均Δf`得到13.28；它是点数估计，不是最长连续端点带宽，更不能与13.20混报。coverage=B/16=82.5%，是频带覆盖比例，不是吸收率。输出点可能包括插值，不声称201个独立频率求解。

## 7.2 最终评分精确构成

| 项 | C中最终规则 |
|---|---|
| 带宽主项 | 3.2B + 0.20B_total |
| 高频端 | f_high≥17.90加14；否则减9(17.90−f_high) |
| 低频端 | f_low≤5.00加8+4(5.00−f_low)；否则减7(f_low−5.00) |
| 低端阶梯奖励 | ≤4.80加7；≤4.60再加10；≤4.45再加14 |
| 参考/目标带宽 | 达到REFERENCE_9X9_BW加6；达到REFERENCE_12X12_BW加14+4(B−该参考值)；达到13.35再加16；达到13.6再加45+8(B−13.6) |
| 谷深 | +0.05×min(abs(minRL),50) |
| 平均裕量 | +0.10×min(mean_margin,18)，其中margin=−10−RL，仅在通过点统计 |
| 太浅惩罚 | −2×shallow_ratio；通过点中RL>−11的比例 |
| 差带宽惩罚 | B<12时再扣12 |

“−10 dB”的动机是把指定反射通道压到10%功率；不是自然界的吸收分界。在总反射/透射核清之后，这类门槛才可能用于总吸收评价。

注意参考常量仍保留历史口径：`REFERENCE_9X9_BW=12.338308457711443`，`REFERENCE_12X12_BW=13.120000000000001`。前者不能为了叙述整齐擅改为端点跨度12.32；评分应按代码常量复算，性能报告则标清端点/点数口径。

几何硬筛选独立于曲线奖励：X保留22–72像素、至多6个连通分量；Y64–105、至多4个分量；孤立点阈值与修复并用（C4324–4332、4630）。**这不要求所有图案只有一个连通块**，也不是制造可行性证明。不合格或求解失败记零分；算法可能存在偏好和盲区，没有系统权重消融。

# 8. 为什么模型后来改变

| 改变 | 当时文稿/记录明确支持 | 今天可以解释，但不能冒充当年决策 |

## 结果能够证明什么

保存数值模型在指定偏振下出现较宽低反射采样区间；自动建模与搜索链有参数、结果与工程可回查；已恢复样点的反射矩阵与功率输出内部相符。论文场/损耗图支持“耗散空间分布不均匀、不同频点分布有变化”的定性观察。

## 结果不能证明什么

不能把13.20直接当完整、稳定、实测的宽带吸收器性能；不能证明双偏振、斜入射、有限尺寸、可制造与材料真实频散；不能把18 GHz当实际物理上边界；不能证明全局最优或0.08 GHz有显著增益。不能由多个谷直接认定若干模态，更不能说已完成multipole/modal analysis。

后期确有网格自适应记录：18 GHz三轮，5462→6621→7408，S差约0.0019609、0.000580563，并有警告。应说“软件内部自适应停止记录存在，但独立收敛验证未完成”，而不是“完全没做网格”或“已经严格收敛”。（G/H日志、审计）

# 12. 一页版流程总结（先读，约3分钟）

**课题**：在2–18 GHz内，让金属背板前的周期电阻膜结构对指定偏振有更宽低反射区间。研究想做吸收，历史GA用的是同模反射代理指标。

**模型**：两块竖直正交PET，表面有0/1电阻图案，底部理想PEC。XY周期表示无限阵列；上方Floquet端口沿−z入射。本工程mode1电场沿y，mode2沿x。X/Y膜名不等于mode编号。

**自动化**：候选→修复/缓存/筛选→Python写CST History→频域求解→保存工程→读复数r11→算dB与fitness→选择/交叉/变异→下一代。师兄给框架，我与AI做具体任务适配与扩展。

**GA阶段**：6×6是30 bit：p6+h6+X9+Y9，片阻固定；9×9默认50 bit固定p/h；最终12×12是四连续量＋两张mask的字典，有骨架与约束，**不是30 bit**。薄实体先于Ohmic；换sheet并不同时放开片阻，双Rs在后续hf阶段才明确启用。

**结果**：最终GA保存r11≤−10 dB区间4.80–18.00，跨度13.20 GHz；后期自适应工程为5.20–17.68、12.48 GHz。82.5%是频带覆盖，不是吸收率。18 GHz是扫描上限。

**验证边界**：PEC令T=0，但总R仍须求和全部反射传播通道。r21是同端口交叉反射，不是穿过背板。近期已恢复四项反射和离散功率：交叉项很小但不能假定为0，另一个偏振接近全反射。功率内一致≠严格收敛≠实测。PET损耗有效设置待核；没有完成模态/多极分析。
