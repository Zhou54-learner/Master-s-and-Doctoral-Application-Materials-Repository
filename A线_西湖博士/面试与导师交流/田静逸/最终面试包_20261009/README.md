## 不能混的五件事

- 6×6早期30 bit ≠ 最终12×12的四连续量＋两张mask。
- 原GA只读r11；近期另恢复全反射矩阵与离散功率，不倒写为本科已做全通道优化。
- 4.80–18.00 / 13.20 GHz为GA保存同模低反射采样指标；后期自适应为5.20–17.68 / 12.48 GHz。
- PEC下T=0仍需加总反射通道；82.5%是频带覆盖，不是吸收率；交叉项不能先验设零。
- 课题组参考、本人＋AI应用扩展、未完成的机制与实验验证必须分开。
