## 田老师版默认定制方向

### 1. PPT 总体
建议 6–8 页、5–8 分钟主陈述，符合老师“简单 PPT”的要求；不默认扩成 15–20 页正式答辩。会议邀请给出的 10:00–12:00 是会议时间窗口，不据此推定申请人需要连续汇报两小时。

### 2. 研究连接
目前可作为待核草案的桥接是：

> 微波电磁结构 / CST 参数化仿真 / 参数搜索 / 模型比较  
> → 微纳光学中的结构—响应问题  
> → 全介质纳米天线及阵列等体系中的光学响应调控。

使用前仍需按田老师公开页面或会议中确认的实际问题复核。强调“物理问题与计算设计思路可迁移”，不把微波与纳米光学说成同一问题，也不声称已有微纳加工、光谱测量、COMSOL 或纳米光子学研究经验。

### 3. 未来方向
田老师要求讲“未来想探索的方向”，建议使用开放表达：

> 对利用物理建模和计算方法理解、设计结构—响应关系保持长期兴趣；希望把已有电磁结构仿真、参数搜索和数据分析经验迁移到微纳光学问题中，并根据具体课题系统学习对应理论与实验方法。

不要为了贴组而直接宣布“博士期间只做全介质纳米天线”。

### 4. 预计重点追问
- 毕设中已有结构 / 仿真流程与本人增量的边界；
- Python-CST 自动化具体做了什么；
- GA 为什么需要、fitness / 搜索逻辑如何理解；
- 薄实体膜与 Ohmic Sheet 比较；
- 结果可靠性与未完成验证；
- 大创、尘埃等离子体两段合作的真实 contribution；
- 为什么从微波电磁转向微纳光学；
- 是否愿意做实验、如何看待计算与实验结合；
- 未来 3–5 年希望形成什么研究能力。
