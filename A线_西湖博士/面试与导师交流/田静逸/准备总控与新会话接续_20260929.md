## 3. 当前对田静逸 / OMAL 的框架性认识

这里只保留用于组织后续学习的工作框架，不替代官方证据。

### 3.1 PI 学术主线

当前工作理解：田老师的研究不是单纯“做超表面”，而是以**介质微纳结构、主动材料和微纳光电器件**为平台，围绕微纳尺度下的**光产生、光调控与光探测**展开。

其研究轨迹可粗略理解为：

> 全介质纳米结构 / 多极共振 / 光学响应调控  
> → 高 Q、anapole、可重构与主动 metasurface  
> → perovskite / phase-change 等主动材料  
> → micro/nanolaser、polarization / chirality、topological / non-Hermitian photonics  
> → 更完整的微纳光电器件与智能设计问题。

这只是学习地图，不代表申请人已经掌握这些方向。

### 3.2 实验室当前能力拼图

公开成员方向显示，组内并非所有学生做同一课题，而是覆盖若干互补能力，包括：

- spin-selective optical metasurfaces；
- AI for Science / intelligent optical design；
- free-space optical computing；
- micro/nano fabrication；
- nanophotonics / micro-nanolasers；
- topological photonics；
- nano-optics / metafiber / metasurface 等。

因此当前更合理的组画像是：**纳米光子学为主轴，计算设计、器件物理、主动材料、微纳加工和实验表征共同组成研究闭环。**

### 3.3 与申请人的潜在接口

当前只把以下内容视为“可迁移接口”，不写成已掌握目标技术：

> 微波电磁结构建模  
> + CST / Python 参数化仿真

待学习内容包括但不限于：纳米光子学具体理论、COMSOL / 其他光学仿真环境、微纳加工、光谱 / 光学测试、具体主动材料体系等。

## 5. 正式写 PPT 之前的三线并行准备

### 线 A｜个人科研与技能体系重建

**目标：** 把“我做过什么”从 CV 文案恢复成可以被连续追问、可以现场解释、必要时可以用最小 demo 验证的真实工作流。

优先级：本科毕设最高；其次二维尘埃等离子体；再其次吸波材料大创 / 合作；第三篇低参与论文只做基本论文理解，不制造历史 contribution；新会议稿待状态和本人贡献另核。

核心产物：

1. 每个项目 ownership 表：
   - 导师 / 师兄 / 合作成员提供或决定的输入；
   - 本人亲自完成的步骤；
   - 已有验证与证据；
   - 尚未完成验证。
2. 本科毕设工作流还原：模型 → 参数化 → Python-CST → GA / 搜索 → 结果读取 → 筛选 → 可视化 → 可靠性边界。
3. 必要时做**当前复原 demo**，例如最小化参数生成、仿真调用、结果解析或 GA toy workflow；必须明确标注“2026 面试复习重建”，不得倒推为本科期间完成的历史贡献。
4. 形成 30 秒 / 3 分钟 / 10 分钟三档讲法。
5. 建立技能矩阵：`Already demonstrated / Transferable / Need to learn`。

### 线 B｜田静逸 / OMAL 研究地图与文献线

**目标：** 不是“刷论文数量”，而是理解 PI 的研究品味、学术演化、当前组真正推进的问题与可能的学生入口。

核心产物：

1. PI 学术轨迹图：浙大阶段 → NTU 阶段 → 西湖独立建组阶段。
2. 当前组方向图：研究主页方向、招生方向、博士后 / 博士生研究主题、平台与协作生态。
3. 文献分层：
   - **Core A：PI 一作 / 通讯、定义其研究主线的关键论文；**
   - **Core B：西湖独立建组后的当前论文，判断组里现在真的在做什么；**
   - **Bridge C：与申请人接口最强的计算设计 / inverse design / intelligent optical design 相关工作。**
4. 每篇重点文献只要求回答：科学问题、物理机制、方法、主要结果、为什么对田老师研究主线重要、与本人的连接在哪里。
5. 区分：本人真正读过 / 只浏览摘要 / 由助手整理。面试中不得假装精读未读论文。

### 线 C｜理论概念框架

**目标：** 先建立“能听懂科研讨论”的共同语言，再选 2–3 个最相关主题深入；不追求十天内成为纳米光子学研究者。

建议层级：

**Level 1｜共同基础语言**
- 频域 Maxwell 方程与边界条件；
- 介电常数、折射率、吸收；
- scattering / transmission / reflection；
- resonance、Q factor；
- near field / far field；
- polarization。

**Level 2｜纳米光子学核心链**
- Mie resonance；
- multipole decomposition；
- electric / magnetic dipole；
- Kerker condition；
- anapole；
- Fano / high-Q resonance；
- BIC；
- chirality / spin-selective response。

**Level 3｜组内进阶方向**
- topological photonics；
- non-Hermitian photonics；
- micro / nanolaser；
- exciton-polariton；
- perovskite photonics；
- phase-change materials；
- metafiber；
- optical computing。

**Level 4｜方法线**
- numerical simulation；
- parameterized modeling；
- optimization / inverse design；
- surrogate model；
- machine learning for photonics。

学习深度采用三档：
- A：会用自己的话解释；
- B：能读懂论文的主要图与公式在证明什么；
- C：能自己建模 / 推导 / 仿真 / 设计实验。

面试前多数概念做到 A+B 即可；与本人潜在入口最相关的 Mie / multipole / high-Q / inverse design 可逐步更深。
