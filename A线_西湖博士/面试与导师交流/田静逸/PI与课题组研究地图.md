## 1. 当前工作框架

暂按以下主线理解，后续用论文和官网逐项验证：

> 全介质纳米结构 / 多极共振 / 光学响应调控  
> → high-Q / anapole / 可重构 metasurface  
> → perovskite / phase-change 等主动材料  
> → micro/nanolaser、chirality / polarization、topological / non-Hermitian photonics  
> → 微纳光源、探测器、metafiber、智能光学设计等器件问题。

这是一张学习地图，不代表申请人已掌握这些方向。

1. 田老师从博士到独立 PI 的研究主线怎样变化？

4. 哪些方向是 PI 本人最长期、最核心的积累？
5. 哪些方向更像组员 / 合作者扩展出的新分支？
6. 如果本人进入组里，最自然的第一步研究接口是什么？
