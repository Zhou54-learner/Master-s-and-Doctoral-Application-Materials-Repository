# 田静逸｜定制映射与 PPT 微调

状态：INTERNAL｜最终 PPT 前置工作页

本页只处理公共主干到田老师场景的 20%–30% 定制，不重复建立个人事实。

## 一、老师已明确要求

- 简单 PPT；
- 教育经历；
- 科研经历；
- 未来想探索的方向；
- 中英文均可。

会议时间等事件以[唯一联系记录](../../联系记录.md)为准，本目录总控仅摘要；私人会议链接不入库。

## 二、项目强调顺序

当前建议：

1. 本科毕设：电磁结构、参数化仿真、搜索与模型比较；
2. 尘埃等离子体：数值数据处理 / 物理分析能力；
3. 吸波材料合作：真实科研协作经历；
4. 其他成果只作背景，不以论文数量作主叙事。

## 三、研究连接页候选逻辑

> 微波电磁结构 / 参数化建模 / 自动仿真 / 受约束搜索  
> → 对结构—场—响应问题形成兴趣  
> → 希望在纳米光子学中系统学习多极共振、微纳器件与实验验证  
> → 长期关注计算设计与真实器件闭环。

该逻辑必须在完成 OMAL 研究地图和重点文献学习后再压缩成 PPT 文案。

## 四、未来方向页边界

优先表达“问题类型”和“能力成长”，不提前宣布博士课题：

- 对物理建模与结构—响应设计感兴趣；
- 希望进一步学习 nanophotonics 的理论、仿真与实验；
- 对 inverse / intelligent design 与器件验证的结合保持兴趣；
- 愿意根据组内具体课题学习微纳加工与光学测试。

## 五、田老师特有追问池

待本 PI 的研究地图与概念学习推进后补充，至少覆盖：
- 为什么从微波结构转向微纳光学？
- 你认为微波和光学尺度的共同点 / 差异是什么？
- 是否愿意承担实验与加工？
- 如何看待仿真、优化与实验之间的反馈？
- 对本组哪类问题最感兴趣，为什么？

## 六、最终定制 Gate

先通过[公共输出规范](../../../公共资料/面试与导师交流中心/公共主干/面试资料母版与输出规范.md)，再检查本场差异：

- 主动引用的论文已由本人读到能解释问题、关键图和边界；不设固定篇数，不要求全领域掌握。
- Why OMAL 有具体公开证据，所用 Mie / multipole / high-Q 等概念能解释；未掌握术语只列待学习。
- 迁移以“可迁移 / 希望学习”表述，不冒充 nanophotonics、nanofabrication、optical characterization 或 inverse design 经验。
- 引用公共成果的版本、沿用页、调整页和 PI 判断来源单列；本轮仅框架，未制作最终 PPT。
