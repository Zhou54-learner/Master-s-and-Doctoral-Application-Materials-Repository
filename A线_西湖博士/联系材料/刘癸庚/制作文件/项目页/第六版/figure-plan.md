# 联系用项目页 v6 图文计划

用途：向 PI 提供一页可快速阅读的研究经历补充。阅读顺序为研究目标、结构、本人工作、同模反射结果；删除与邮件重复的学习意愿末段，不增加未来课题或验证计划。

| 面板 | 性质与来源 | 后端 |
|---|---|---|
| 正交结构及 X/Y 展开图 | 沿用第四版依据归档掩码、尺寸和代码绘制的示意；不是 CST 截图 | 原生 SVG 的已有矢量 PDF，不重绘 |
| 同模反射曲线 | 沿用第四版 201 点保存数据；不新增仿真、平滑或插值 | Matplotlib 的已有矢量 PDF |
| 页面 | 澄清两片电阻膜各自的片阻及图案离散规模 | ReportLab 文本 + PyMuPDF 矢量组合 |
