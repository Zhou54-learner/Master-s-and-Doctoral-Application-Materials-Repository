## 3. 新筛选原则

### 3.1 不再只按研究主题表面匹配

只要存在以下任意一到两条真实接口，就应继续核查，不要因为博士核心方法当前不会而提前淘汰：

- 电磁 / 波动物理 / 光子学；
- 参数化物理建模与商业/科研求解器自动化；
- Python 科研自动化、批量仿真、数据处理；
- 结构搜索、优化、inverse problem；
- 材料—电磁响应；
- 数值物理、科学计算、多物理场；
- 实验自动化/数据链路（仅作为可迁移接口，不声称已有实验平台经验）。

### 3.2 年轻PI不默认更容易

必须明确写入总表：

> **“新组/年轻PI”同时存在正向和负向因素。**

可能的正向：组正在搭建、确需第一批学生、课题和工作流尚未固化。  
可能的负向：tenure / 首轮成果压力高、可能更需要能立即产出的成熟学生、对学生质量不确定性容忍度反而更低。

因此“组龄”只能作为一个变量，不能直接转换为 `Admission Feasibility +分`。

### 3.3 中文沟通环境作为正式维度，但不能按姓名/国籍直接判定

本人偏好中国PI或中文科研沟通友好的组，原因是希望降低入组第一年的 communication/onboarding friction，而不是排斥英文科研。

需要分别核：

- PI 能否日常中文沟通；
- 组内主要学生构成；
- 组会/日常技术讨论语言（如无证据，标 UNKNOWN）；
- 是否有中文母语师兄师姐帮助新人上手；
- 英文主要用于论文、会议还是日常研究全流程。

**不得仅凭中文姓名判断“中文工作环境”。**

## 4. 每位PI必须分开评估的4个核心维度

1. **Research / Training Fit**：课题本身与训练质量是否值得读；
2. **Admission Feasibility**：以申请人当前履历，现实竞争力如何；
3. **Communication / Onboarding Friction**：入组后的语言与工作流上手摩擦；
4. **Transferable Skill Value**：即使方向妥协，5年后能留下哪些可迁移硬能力。

另加：

- `Evidence Confidence`：HIGH / MEDIUM / LOW；
- `Application Priority`：REACH / MATCH / OPPORTUNITY / OBSERVE；
- `Contact Cost`：低 / 中 / 高（需要多少专项论文学习、材料定制和技能补课才能发第一封）。

不要把 `Application Priority` 等同于绝对录取率。

## 5. Admission Feasibility 必查项

每位PI尽量核以下信息，并允许 UNKNOWN：

- 2027 是否公开招 PhD；
- 招生学科；
- 是否接受本科直博；
- 当前组成立年份；
- 当前博士人数；
- 近2–3年每年新入组博士人数；
- 能找到的本科直博学生本科院校；
- 能找到的入组前论文/一作情况；
- 招聘文本是 `required`、`preferred` 还是未提论文；
- 是否有 multiple openings / several openings / 明确名额；
- 是否需要已经掌握特定方法栈；
- 理论/计算/实验的实际工作比例；
- 是否有年轻组“急成果、偏成熟学生”的迹象；
- 是否存在明确培养型措辞，如“不要求相关背景”“可根据个人情况启动课题”等。

不能找到的信息写 `UNKNOWN`，不得根据 PI 年龄、名校履历、论文档次或组规模自行推断。
