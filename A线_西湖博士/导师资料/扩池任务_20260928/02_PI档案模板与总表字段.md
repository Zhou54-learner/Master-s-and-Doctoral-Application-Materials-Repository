# PI档案模板与导师池总表字段

用途：Work 在扩池后统一新增/旧有 PI 的表达，避免旧8位长报告、新PI零散笔记和联系材料互相混用。

## 一、导师池总表建议字段

| 字段 | 说明 |
|---|---|
| PI | 中文/英文名 |
| School / Subject | 官方主聘学院、招生学科；未知则UNKNOWN |
| Group stage | 成熟组 / 成长期 / 新建组；只描述，不直接加分 |
| Existing bridge | 申请人哪一段真实经历可作为入组接口 |
| 2027 signal | CONFIRMED / GENERAL OPENING / UNKNOWN / TIMING RISK |
| Bachelor-entry | 已确认本科可申 / 待核 |
| Publication signal | Required / Preferred / Not mentioned / Anecdote only |
| Current PhD size | 数量与证据日期；未知则UNKNOWN |
| Recent intake | 近2–3年入组人数，如可核 |
| Student pre-entry evidence | 入组前院校、一作/项目等，只记录能证明“入组前”的材料 |
| Research / Training Fit | 独立评分+理由 |
| Admission Feasibility | 独立评分+理由 |
| Communication / Onboarding | LOW / MEDIUM / HIGH friction + 证据 |
| Transferable Skill Value | 独立评分+5年后技能资产 |
| Contact Cost | LOW / MEDIUM / HIGH |
| Priority | REACH / MATCH / OPPORTUNITY / OBSERVE |
| Confidence | HIGH / MEDIUM / LOW |
| Next action | 深查 / 发信准备 / 问同学 / 等批次 / 暂缓 |
| Sources | O/P/S/A/I + URL/日期 |

## 二、单个PI轻量dossier模板

### 0. 一句话判断

只写一句：为什么值得/不值得当前申请人继续投入。

### 1. 官方身份与招生

- 学院：
- 招生学科：
- 入职年份：
- 2027 招生信号：
- 本科直博是否确认：
- 英语门槛风险：
- 公开材料要求：

### 2. 研究主线与实际工作方式

不要只抄论文题目。拆成：

- 研究对象；
- 核心方法；
- theory / computation / experiment 比例（证据不足则UNKNOWN）；
- 新博士最可能先学什么；
- 是否需要昂贵/高摩擦实验平台；
- 是否存在可积累科研资产（代码、数据、工作流、器件平台等）。

### 3. 与申请人的真实接口

必须分成：

- `Already demonstrated`：申请人已经真实做过；
- `Transferable`：可迁移但尚未证明；
- `Need retraining`：入组后需系统重学；
- `Do not claim`：不能在套磁中冒充已有能力。

### 4. Admission Feasibility

至少回答：

- 公开招人是 ongoing 还是明确2027；
- 组规模和招人速度；
- 近年学生背景；
- 入组前成果能否查到；
- 是否出现一作/SCI硬筛信号；
- 新组是否可能存在成果压力（只能写风险，不做无证据断言）；
- 申请人相对于该组常见候选人的明显短板与优势。

### 5. Communication / Onboarding

- PI 日常中文：证据/UNKNOWN；
- 组会语言：证据/UNKNOWN；
- 中文母语学生支持：证据/UNKNOWN；
- 对申请人第一年额外语言成本的判断。

### 6. 五年训练资产

即使研究方向不是长期首选，也要回答：

> 如果读完这个博士，申请人会真正掌握什么可迁移的硬能力？

例如：DFT/MD/HPC、nanophotonics、FEM、scientific ML、超快光谱、微纳加工、实验自动化、inverse problem、数值多物理场等。

### 7. 风险与待确认

严格分：

- `KNOWN`：公开事实；
- `ANECDOTE`：组内/第三方转述；
- `INFERENCE`：分析；
- `UNKNOWN`：目前查不到。

### 8. 首封策略（只有进入准备阶段才写）

首封只回答：

- 用哪一段个人经历打开；
- 为什么这个组“能接住”已有能力；
- 问什么招生问题；
- 哪些具体方向不应提前声称兴趣/掌握。

不要为每个池中导师提前生成完整邮件。

## 三、年轻PI判断规则

年轻PI必须同时记录两面：

**机会：**
- 第一批学生/新工作流确实需要人；
- 可能更愿意按未来方向共同搭建能力；
- 层级少，直接接触PI概率可能更高。

**风险：**
- tenure/首轮论文压力；
- 新平台尚未完全稳定；
- 对学生即战力要求可能反而更高；
- 培养记录短，毕业路径、管理风格缺少样本。

没有学生/组内证据时，结论只能写“机会与风险并存”。

## 四、中文沟通偏好规则

申请人偏好低 communication friction，但英文科研能力仍是博士训练的一部分。因此：

- 中文工作环境是排序优势，不是绝对门槛；
- 外籍PI不直接删除，如 admission/training 明显好仍保留补充面；
- 中国PI也不直接标 LOW friction，除非有学生构成、组会介绍、组内反馈等证据；
- 套磁邮件不要直接问“组里讲中文吗”，优先通过成员/同学/后续交流自然确认。

## 五、排序原则

当前阶段不再追求“找唯一最理想导师”，而是构建组合：

- **REACH**：强匹配但高筛选门槛/名额少；
- **MATCH**：研究、训练、可达性较均衡；
- **OPPORTUNITY**：方向可能妥协，但招生接口/训练资产值得尝试；
- **OBSERVE**：跨度大、名额或学科不清，保留但低投入。

目标是扩大真实选择权，而不是人为制造“保底导师”。博士申请不存在真正保底。
