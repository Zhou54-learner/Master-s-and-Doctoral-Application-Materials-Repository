# 2027 香港研究型学位｜第二轮项目级核验与分级

更新：2026-09-29  
性质：对第一轮 PI 广扫做“当年项目 / 学位入口 / funding / 明确 opening”核验。第一轮文件保留为历史发现池，本文件优先级更高。

## 0. 方法修正

第一轮主要解决“哪些方向和 PI 能从本人真实经历讲通故事”；第二轮把以下证据放在单纯方向匹配之前：

1. 2027 是否真的开放 MPhil / PhD；
2. 当年具体 project 是否注明 MPhil、PhD 或两者；
3. 是否公开写明 student numbers / openings / accepting students；
4. studentship 是否随 admission 自动考虑、另行竞争，或仅部分名额有资助；
5. 本人的 80.2044/100、中段排名证据、理论主干低分与 CET-6 471 会在哪个 gate 产生实质风险；
6. 故事匹配是否来自已核实经验，而不是未来计划。

因此第二轮允许对第一轮 T1/T2/T3 直接升降级。总“线索人数”不再作为质量指标：跨 Physics / Materials / ECE / Mechanical 等入口后，命名线索已明显超过第一轮 51 人，但真正值得材料投入的对象应压缩到约 30–40 个，首批深查约 12–15 个。

# 7. Funding修正

### CUHK
Physics / MSE regular MPhil-PhD studentship目前官方写HK$19,100–19,660/月，无需另行申请；这是优质admission-linked资金结构。但本人是否满足项目录取要求仍独立判断。

### CityUHK
只有 government-funded full-time research place 才能把studentship纳入预算。eligible new full-time students作为admission的一部分自动考虑；Physics页面还写studentship通常要求至少upper-second equivalent，publication record可能有例外。本人成绩等效仍需核，不能先判Budget PASS。

### HKBU
UGC-funded与self-funded并存；studentship按academic merit由department决定并写入offer。**没有studentship即不通过本人预算gate。**

### PolyU
2026年更新后的PRPgS明确同时面向full-time PhD/MPhil；申请RPg时并行考虑，无需单独申请，annual stipend HK$230,640。2027/28无stipend全日制MPhil/PhD学费HK$99,000/年、有stipendHK$49,500/年。因此 **offer必须连同PRPgS/其他stipend结果一起判断**，不能把PolyU MPhil自动当低成本。

### HKU
PGS通常要求first degree达到Second Class Honours First Division/equivalent以上，且subject to funding availability。本人成绩等效不明，HKU仍是选择性冲刺而非预算基本盘。

# 8. 当前战略结论

香港线不再是“HKUST/CUHK计算物理”一条窄线，而是：

> **MPhil基本盘 + 项目/PI驱动错位申请 + regular PhD冲刺 + HKPFS彩票 + paid RA桥接。**

目前最有价值的“错位”不是去找所谓冷门学校，而是找：

- classical wave / acoustic metamaterials；
- integrated photonics / applied electromagnetics；
- soft matter / active matter / complex fluids；
- functional materials / experimental condensed matter；
- spectroscopy / optical devices；

这些方向既能由本人真实经历解释，又通常不需要和纯CS/LLM申请池使用同一套背景竞争。但没有公开申请数据时，不宣称其真实录取率更高。

下一步：对T1约12–15个对象逐一做近3–5年论文、学生背景、组规模、2027 opening、funding、是否适合MPhil、套磁切入点的独立PI卡，最终压缩成首批8–12个真实联系对象。
