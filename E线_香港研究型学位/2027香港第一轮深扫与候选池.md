# 3. 不能简单写成“低竞争”的错位机会

以下方向值得作为拥挤度错位探索，但目前没有公开录取率证明它们“更容易”：

1. **classical wave / acoustic metamaterials**：HKBU Guancong Ma、HKUST wave-functional materials 等；
2. **soft matter / active matter / complex fluids**：HKUST Rui Zhang / Qin Xu / Yilong Han，CUHK Lei Xu / Yilin Wu 等；
3. **integrated photonics / applied electromagnetics**：CityU Sai Tak Chu / Alex Wong，HKUST ECE 若干组；
4. **functional materials / device physics**：HKUST Shiming Lei、HKBU optoelectronics、PolyU PM；
5. **spectroscopy / experimental materials**：可用光学+材料经历解释，但入组需要重新训练实验技术。

判断竞争时优先找：公开 openings、2027 project list、当前组规模、近年毕业/新生、PI 是否新扩组、funding/project grant。不得用“学校排名稍低”“方向看起来冷门”“PI年轻”直接推出低竞争。

# 4. 申请故事模板（仅内部逻辑，不是套磁正文）

## WAVE

应用物理 → CST 参数化电磁结构与吸波设计 → 对人工结构调控波传播形成兴趣 → 研究生转向 metamaterials / photonics / phononics / THz / integrated wave devices。

## SOFT

尘埃等离子体晶格波与 MATLAB 数据分析 → 对相互作用多体系统、集体动力学和非平衡行为形成兴趣 → soft matter / active matter / complex fluids / turbulence / complex systems。

## MAT

吸波材料大创/论文 + 固体物理训练 → 接触材料结构–电磁响应关系 → 转向 functional / quantum / nano materials 或器件，强调愿意补实验表征/微纳加工。

## OPT

光学、傅里叶光学、电磁学课程表现较好 + CST 波动模拟 → integrated optics / nanophotonics / spectroscopy / optoelectronics；不把课程成绩夸成科研能力。

## COMP

Python 调用 CST、批量计算、参数搜索与数据处理 → 已证明能把物理问题转成可复现计算流程 → 希望学习更系统的 numerical / scientific computing；明确尚未做 DFT/MD/深度学习，不伪造技能。
