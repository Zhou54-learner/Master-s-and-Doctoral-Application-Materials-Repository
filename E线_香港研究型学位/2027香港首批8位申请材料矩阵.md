## 3. 材料使用原则

1. **CV 不按 PI 重写事实，只调整顺序和 Research Interests。**
2. **Project Sheet 不是默认附件。** SOFT/COMP 联系不附，避免让电磁毕设压过真正的迁移故事。
3. **SOP 必须回答“为什么从本科经历迁移到该问题”，而不是伪装成已经在做目标方向。**
4. 论文贡献只写已核实 contribution；`Inorganic Chemistry` 论文目前只保留 authorship，不补写个人贡献。
5. 任何提到 AI / machine learning 的句子都必须区分“research interest / intended training”与“established skill”。
6. 无 funding 的 MPhil offer 一律不进入最终选择；这一点不写进 SOP，而在 offer decision stage 执行。

## 4. 申请系统材料优先顺序

正式申请开始后，每校按以下顺序补：

1. application form + programme/project choice；
2. English CV；
3. transcript / degree / ranking documents；
4. personal statement / SOP / research statement（按校方 prompt）；
5. referee information + referee briefing pack；
6. English score或 pending 证明（按各校规则）；
7. funding/studentship 相关表格；
8. PI-specific supplementary material（如 Project Sheet）。
