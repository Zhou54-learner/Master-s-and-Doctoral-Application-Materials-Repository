## 2. 联系节奏

沿用其他路线的 3 天反馈窗口，但改为“按批次等待”，不是“每位 PI 串行等待”。

原则：

- 每轮同时联系 2–3 位 PI；
- 同一轮尽量来自不同学校；
- 同一学校、尤其同一院系的 PI 不在同一轮同时联系；
- 同校 PI 至少错开一个 3 天窗口，避免短时间内多头联系造成叙事和沟通冲突；
- 每轮发送后等待 3 天，再根据回复决定下一轮是否按原计划推进；
- 若某校 PI 在 3 天内明确 positive，可暂缓同校下一位，先跟进该机会；
- 若明确无名额/不匹配，可按计划推进同校下一位；
- 若无回复，不把“沉默”当拒绝，但不因此阻塞其他学校并行推进。

## 4. 回复处理

- `POSITIVE`：PI 明确愿意看材料、确认有 2027 MPhil/RA 空间、邀请进一步沟通或建议申请。进入优先跟进，准备 PI-specific CV / SOP / interview。
- `NEUTRAL`：回复方向匹配但未承诺名额，或只建议走系统。保留正式申请，但不停止其他学校推进。
- `NEGATIVE`：明确无名额、不招 MPhil、方向不合。停止该 PI，必要时启用同校下一候选。
- `NO REPLY`：3 天窗口后进入下一轮；后续可在合适时间做一次 follow-up，但不阻塞其他学校。

## 5. 执行纪律

1. 先深查完 8 人，再发送首封；不边查边随机发。
2. 首封目标是确认 opening / fit / entry，不是要求导师提前承诺录取。
3. 不在同一时间向同一院系多个 PI 发送高度相似邮件。
4. 正式申请材料投入优先给 positive / strong-neutral PI；无回复者根据项目本身价值决定是否仍投系统。
5. 所有发送、回复与状态变化写回工作台；未发送前保持 `REVIEW` / `CANDIDATE`，不得写成 SENT。
