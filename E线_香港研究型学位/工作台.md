## 1. 路线定位

本路线独立管理香港特别行政区研究型学位机会，不与“其他境外低成本升学”混放。核心对象包括：

- MPhil / research master；
- regular funded PhD；
- HKPFS 作为 PhD 高收益冲刺叠加层；
- 6–12 个月 paid RA / predoc bridge；
- 与上述路径直接相关的 PI / project / research group；
- 物理之外、但能与现有经历形成合理迁移的 Materials / ECE / Mechanical / Nano Science 等相邻研究单位。

香港线不等同于“计算/AI线”。本科工作与研究生课题不要求同题，只要能够用真实经历建立合理的物理、方法或问题迁移链条即可进入发现池。

## 3. 当前四层路径

1. **主路径：MPhil / UGC-funded research master**  
   对当前成绩结构通常比本科直博更现实；重点看 PI fit、项目资格、studentship 是否随录取或自动考虑。
2. **冲刺路径：regular funded PhD**  
   只在学校本科直博门槛允许、PI 高匹配且 funding 可过预算 gate 时投入。
3. **彩票层：HKPFS**  
   可与 regular PhD 同时尝试，但由于本人均分/排名并非顶尖，不把 HKPFS 作为预算安全基础。
4. **桥接层：paid RA / predoc**  
   若 2027 没有满意 offer，或出现与本人经历高度贴合、能形成论文/推荐信/实质研究资产的 6–12 个月岗位，可作为 2028 升级路线。RA 岗位与学位申请分别维护状态。

## 4. 故事簇

- **WAVE｜波动物理 / 电磁 / 超材料 / 光子学**：CST 参数化电磁仿真、吸波结构 → metamaterials / metasurfaces / photonics / plasmonics / THz / acoustic-wave physics。
- **MAT｜材料 / 器件 / 实验凝聚态**：吸波材料科研、固体物理基础 → functional materials / nanomaterials / quantum materials / optoelectronics / device physics。
- **SOFT｜软物质 / 复杂系统 / 非平衡**：尘埃等离子体、MATLAB 数值和数据分析 → collective dynamics / soft matter / active matter / complex systems / turbulence。
- **COMP｜计算 / 数据 / 模拟**：Python–CST 自动化与参数搜索 → computational physics / scientific computing / numerical modelling；不得虚构 DFT/MD/ML 实战。
- **OPT｜光学 / 光谱 / 光电**：光学 86、傅里叶光学 97.4、电磁学 87 → spectroscopy / integrated optics / photonic devices / light–matter interaction。

一个 PI 可同时属于多个故事簇。故事匹配不代表已有对应专业技能；申请材料必须明确“已有可迁移训练”与“入组后需要学习”的边界。

## 5. 分级语义

PI / project 分级只表示**下一步尽调和材料投入优先级**，不等于录取概率：

- **P1 / T1｜优先深查和首批联系候选**：故事自然，研究学位入口现实，且存在当年项目/公开 opening 或较强招生证据；
- **P2 / T2｜值得申请**：故事成立，但导师热度、成绩门槛、学院跨度或招生证据增加不确定性；
- **P3 / T3｜条件尝试**：方向相邻但需要更强转向叙事，或资金/资格/竞争风险较高；仅在资源允许时推进；
- **WATCH｜观察/冲刺层**：HKPFS、明显 first-class / outstanding-performance 导向的本科直博、资金未过 gate 等，不作为基本盘。

“热门/不热门”若无公开申请数据，只能作为低置信度拥挤度代理，不写成真实录取率。

## 7. Funding gate

每个项目至少分别记录：

1. admission eligibility；
2. studentship 是否 admission-linked / 自动考虑 / 另行竞争；
3. 无 studentship 时学费与生活成本；
4. 取得 studentship 的现实概率判断及依据；
5. 资金续期条件；
6. 是否满足本人净支出与现金占用上限。

只有获得可支持正常生活的 studentship / stipend，或经完整净成本测算仍满足预算，才可标记 `Budget PASS`。奖学金“可申请”但概率低时标记 `HOLD unless funded`。

当前资金结构重点：

- **CUHK**：regular MPhil/PhD studentship 属优质 admission-linked 结构；录取资格仍独立判断。
- **CityUHK**：只有 government-funded full-time place 才把 studentship 计入预算；self-financing non-local 不进入预算基本盘。
- **HKBU**：UGC-funded / self-funded 必须区分；无 studentship 不过本人预算 gate。
- **PolyU**：RPg申请时可并行考虑 PRPgS，但不得预设获奖；offer 必须连同 stipend/学费结果一起判断。
- **HKU**：PGS 成绩等效门槛对本人更不利，因此只做高匹配选择性冲刺。
